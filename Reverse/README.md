# Reverse proof search

`Reverse` works backward from verified consumers toward the exact open
obligations that would feed them. A task pins the relevant revisions, theorem
or alternative, consumer chain, semantic fences, regressions, and acceptance
commands.

Runs classify their outcome as a proved adapter, exact no-go result, typed
obstruction, refined open obligation, or no result. Search traces are evidence;
only kernel-checked Lean enters the trusted library.
