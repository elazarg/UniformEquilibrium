`UniformEquilibrium/Diagnostics/Quitting/ScreenedSingletonFiberStrictGap.lean`

That last premise is raw positivity somewhere on this fixed fiber, not a
selected favorable maximizer. It is appropriate for the fixed-fiber theorem,

Both extrema are produced internally using63 and64. The maximizing s has
positive eta because it dominates the existential positive witness. Its full
actual reward table is unit-bounded by the two-block lemma. Every actual
profile has E ≥ eta, so this applies to the internally minimizing screened
root's actual one-date-then-Never profile.

If strict inequality fails, these two inequalities force E=eta. Only THEN
does the proof construct global minimality against EVERY actual behavioral
profile and positivity at the screened profile. The current
`quittingTerminalDeviationDebt_eq_exploitability_of_attained_positive_minimum`
derives that every player's complete debt equals that same positive E. The
frozen `not_positive_equal_screened_debts_of_polynomial_ne_zero` contradicts
these actual all-player ties, at the same b, same s, and same screened root.
No actual attainment of eta was assumed before this contradiction, and no
response cap needs an attaining reply.

The returned gap is exactly the screened minimum minus the singleton-fiber
maximum and is strictly positive. Output retains the maximizing s, all its
competitor inequalities, the same screened minimizing root for all real
singleton vectors, and the exact gap identity. These objects all precede the
final quantifiers over the WHOLE closed singleton cube and EVERY screened
root. Hence eta(b,s_max)+gap ≤ E_b,t(q) holds uniformly on that same fiber.
The final boundedness condition on t is not used by the comparison proof
because the screening invariance/minimum is valid for all real t; this is a
sound strengthening, not a missing assumption. The polynomial is not silently
recomputed after changing b, and no favorable selected-source fields occur.
