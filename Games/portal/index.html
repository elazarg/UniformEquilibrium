What "survivor" means, exactly: a surviving table has withstood some bounded amount of automated and human attack effort — no more, no less. It is not a theorem, and it is not a verified counterexample to anything. A table's tier records how hard it was attacked, never how right it is. The tiers under "still standing" run from least to most effort spent failing to kill it; the tiers under "killed" run from a narrow numerical margin to an exact, rational-arithmetic confirmation.
