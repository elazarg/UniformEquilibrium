The ledger

This is the research view, and the only place this game speaks plainly. The game is a search for four-player quitting reward tables that resist every approximate equilibrium the portal can find. A "settled room" is a periodic behavioural profile whose exploitability the portal's engine measures below the kill threshold 0.02 on this table: bounded numerical evidence that the table is not a counterexample. It is not a theorem. Nothing you do here is recorded until the server engine re-scores it; the live numbers below come from an in-browser port of the same evaluator and drive feel only. Sealing a groove first asks the engine to snap the hazards to small-denominator rationals and re-verify in exact arithmetic; the "exact" tier means exactly that, for that one profile on that one table, and nothing about any other profile.
