The ledger

Everything the game keeps behind the fiction: the reward table each creature is drawn from, the structural checks a specimen has to pass to be shown at all, and the actual numbers behind today's readings. Nothing here is needed to play.

Each score is a quick-attack floor from the shared engine — the best a fast, bounded set of attackers could do against this table just now. A high score only means today's attackers didn't beat it; it is never proof the table resists every possible strategy. Specimens that clear the kill line get a slower, fuller check before anything is kept.

Bred offspring move in discrete 1/8 steps from their parents — a deliberate restriction (see README) so a lineage stays a visibly related family instead of unrelated tables that happen to sit next to each other. It narrows what this pen searches; it says nothing about the wider, unrestricted table space, and passing this screen is never coverage of it.
