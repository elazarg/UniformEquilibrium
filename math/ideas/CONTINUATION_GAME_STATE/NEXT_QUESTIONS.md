# Next Questions

These are research questions, not claims that the construction advances the
Fin4 proof.

## 1. Pair-kernel sufficiency for the surviving paid-pair seam

For a source-attached paid pair row in Fin4, store the ordinary law, every
unary completed response graph, and every ordered pair response surface.

Can the actual paid endpoint update and the next source regeneration be
computed from these data with no third-order replacement coordinate?  Either
prove closure for the exact sequence of operations used by the current
consumer, or give a three-/four-player counterexample with identical pair
data and different regenerated outputs.

This is the most bounded follow-up.

Before enlarging the state, separate the bounded-date case using
`FIXED_DEADLINE_HORIZONTAL_CONTINUITY.md`.  Pair kernels are only relevant if
the consumer needs a renewable passport after an unbounded or mixed-law
replacement.

## 2. Response-graph near-return consumer

Suppose actual finite chronologies are already supplied, every edge is
punishment-admissible, their cumulative paid charge has a fixed positive
floor, and their start/end completed response-graph states converge to one
target.

Does the existing positive near-return compiler apply directly?  If not,
identify the first missing field.  The likely value of the response graph is
uniform control of every deadline, including escaping ones, rather than
production of the chronology.

## 3. Joint boundary-fibre compatibility

`INFINITY_FIBER_UNIVERSALITY.md` settles the one-coordinate complexity
question negatively: already with two players an individual infinity fibre
can be any compact subset of a reward interval containing its endpoints.

Characterize which *joint* tuples of response fibres, terminal bubble laws,
and player-deleted laws can arise from one common product-clock sequence.  Is
there a finite family of compatibility identities, or does joint
realizability itself require retaining a marked absorption hyperspace?  This
is where product provenance may still cut down the coordinatewise universal
hyperspace.

## 4. Closed replacement diagrams and amalgamation

Define the closed one-step horizontal replacement relation by jointly closing
source, replacement law, and target.  Determine a necessary and sufficient
finite compatibility condition under which two consecutive witnesses admit
one common actual realizing sequence.

A negative example would be valuable: two individually realizable completed
replacement edges with a common middle state but no jointly realizable
two-edge diagram.

## 5. Static discontinuous-game route

Identify each player strategy with a compact stopping law.  The quitting game
becomes a compact convex normal-form game whose payoff is multilinear on
actual laws but discontinuous at relative-time escape.

Can a known discontinuous-game equilibrium criterion be checked using the
explicit response-graph boundary fibres?  In particular, does failure of
better-reply security have exactly the positive-gap inert-machine form, or
does it occur already in tables with obvious equilibria?

The latter falsification should be attempted before importing general fixed
point machinery.

## 6. Consume the all-Continue response bubble

The calculation in `ALL_CONTINUE_BOUNDARY_FIXED_POINT.md` gives an explicit
fixed boundary state: finite deadlines all have the solo value, while the
entire inherited response spectrum lies in the infinity fibre.

Under positive-minimum source provenance, does a nontrivial infinity fibre
force a finite source-matched response window, an exact deletion, or a support
drop?  Or can an explicit zero-minimum table realize every local feature of
this boundary state, proving that still more global data are necessary?
