# Open-question backlog

These are open but subordinate or speculative questions removed from the
priority `questions/` set. They include entrance adapters, optional direct
shortcuts, umbrella formulations, and alternative proof programs.

They are retained for mathematical reuse, but they are not maintained as an
exhaustive or current classification of the conjecture frontier. A file should
return to `questions/` only when its solution would independently close the
conjecture, eliminate an exhaustive chamber, or provide a complete exact
counterexample route.
