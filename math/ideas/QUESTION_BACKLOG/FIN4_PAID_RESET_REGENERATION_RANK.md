# Orient paid/reset regeneration by a finite rank

## Mathematical data

Let a four-player quitting game have positive minimum total debt $D_*>0$
and a terminal exploitability gap.  Suppose an actual source profile carries:

- a literal paid first-disagreement row of fixed positive gain;
- a reset player with zero unrestricted debt;
- a positive opponent-incidence coordinate in the same terminal law; and
- the global minimum semantic point used by the reset construction.

Assume the maximal exact product root against the source cap has positive
absorption.  Prefixing this root once produces an actual descendant which:

- has strictly smaller total debt;
- retains a shifted paid row with positive gain;
- retains zero debt for the reset player and positive opponent incidence;
- belongs to the same terminal-semantic/law carrier; and
- admits a fresh fixed-law reset dispatch.

The same alternative is available for the literal owner-repaired source.

## Question

Turn this actual strict-debt regeneration into one of:

1. a finite source-preserving rank which strictly decreases on every
   recursive regeneration and whose terminal states have closing consumers;
2. a positive cumulative admissible-payoff near-return;
3. terminal approximate Nash profiles for every positive error; or
4. a contradiction to the positive exploitability gap.

An explicit four-player table supporting an infinite regeneration machine and
a fixed positive all-behavior exploitability gap is an acceptable refutation.

## Renewal requirement

The state at each step must retain enough literal data to repeat the same
theorem: paid row, reset coordinate, positive incidence, terminal law, actual
source profile, and the comparison with the same global minimum.

Strict decrease of a bounded real debt is not well founded.  A proposed rank
must be finite or otherwise provably well founded and must not be reset by
choosing a new parent at each step.  Alternatively, an infinite chain must be
compiled into one fixed return target with positive cumulative charge.

## Nonanswers

- the one-step regeneration itself;
- iteration indexed only by decreasing real debt;
- source reconstruction with no rank or terminal dispatch;
- a rank comparing each child to a newly introduced local parent; or
- a compact cluster detached from the literal paid/reset chronology.
