# Finite marked-order compactness and the diffuse-clock no-go

Identity: `CODEX_SPINOZA`

## Current status

**Ordinary-mathematics compactness and reprojection theorems plus exact
regressions; no Fin4 consumer yet.**  A finite family of moving pure-time
responses has a source-attached compact state: the distribution of the weak
order type of the four source clocks and the marked response clocks.  It
preserves the terminal payoff and every marked replacement payoff exactly in
the limit.  If one mark is asymptotically cap-attaining for each player, it
also preserves the four numerical cap limits.  One common midpoint-rank map
preserves every terminal law, marked response, and literal update in a fixed
finite diagram, and the full obstacle hypographs form a compact generalized
trace with cap suprema continuous under Hausdorff convergence.

The generalized hypograph is not automatically generated by its limiting
rank laws.  Independently reranked sources can have identical ranked laws and
different caps because calendar adjacency changes which cuts exist.  More
importantly, a multiscale compactification made only of countably many tight
additive translates is incomplete: uniformly diffuse clock clouds have no
nonzero translated profile but carry an order-one terminal law.  The next
viable compact state must therefore retain a diffuse ordered-rank layer,
separated atoms, Never, and the full cut/obstacle passport.

This note develops the counterfactual profile-decomposition target proposed
in
`CODEX_SPINOZA__COUNTERFACTUAL_SCALE_AND_SOURCE_ANCHOR_META_AUDIT.md`.  It
corrects the naive interpretation of its ``finite or countable rooted scale
object'': nodes cannot all be tight translates.

## 1. Self-contained setting

Let `I` be a finite player set, with `|I|=4` in the intended application.
An actual behavioral profile is equivalently a product of stopping laws

\[
 \sigma=(\mu_i)_{i\in I},
 \qquad \mu_i\in\Delta(\mathbb N\cup\{\infty\}).
\]

Write \(T_i\) for independent random clocks with these laws.  Their weak
order type records, for every pair of labels, whether the corresponding
clocks are earlier, tied, or later, with \(\infty\) distinguished from every
finite clock.

For a deterministic pure response time \(t\), the payoff of player \(i\)
after replacing its complete strategy is determined only by the weak order
type of

\[
 \{t\}\cup\{T_j:j\ne i\}.
\tag{1.1}
\]

The prescribed terminal coalition and payoff are determined only by the weak
order type of \(\{T_j:j\in I\}\).  Calendar distances never occur in either
calculation.

## 2. Finite marked-order compactness

Fix a finite mark set `A`.  For every `n` and every mark `a in A`, let
\(t_a^n\in\mathbb N\cup\{\infty\}\) be a deterministic clock.  The intended
marks include one selected near-best response for each player, but the result
does not require that interpretation.

Let \(\Omega_{I,A}\) be the finite set of all weak total orders on the
labelled set

\[
 I\sqcup A
\]

together with the designation of which final equivalence class, if any, is
the common symbol \(\infty\).  Order types which identify two distinct
deterministic marks whose numerical clocks are different simply receive zero
probability.

For a profile \(\sigma^n\), sample its independent source clocks and adjoin
the deterministic marked clocks.  Let

\[
 p_n\in\Delta(\Omega_{I,A})                         \tag{2.1}
\]

be the resulting order-type distribution.

### Theorem 2.1 (source-attached finite marked compactness)

Every sequence \((\sigma^n,(t_a^n)_{a\in A})\) has a subsequence on which
\(p_n\) converges to some

\[
 p\in\Delta(\Omega_{I,A}).                          \tag{2.2}
\]

For every bounded quitting reward table:

1. the prescribed terminal payoff \(U(\sigma^n)\) converges and is a fixed
   linear functional of \(p\); and
2. for every mark `a` assigned to player `i`, the complete-replacement payoff

   \[
   U_i(\delta_{t_a^n},\sigma^n_{-i})                 \tag{2.3}
   \]

   converges and is a fixed linear functional of \(p\).

All limits come from the same source sequence.  No payoff/cap pair is
reselected independently.

**Proof.**  The set \(\Omega_{I,A}\) is finite, so its probability simplex is
compact.  Select a convergent subsequence of (2.1).  On each order type, the
first source coalition is fixed; its reward gives the prescribed-payoff
functional.  After replacing player `i` by a marked deterministic clock, the
first coalition in (1.1) is also fixed on each order type; its reward gives
the marked-response functional.  Expectations are finite sums against
\(p_n\), so convergence of \(p_n\) proves both assertions.  \(\square\)

### Corollary 2.2 (four selected caps pass numerically)

For each player \(i\), suppose `A` contains a mark \(a_i\) satisfying

\[
 U_i(\delta_{t_{a_i}^n},\sigma^n_{-i})
 \ge B_i(\sigma^n)-\varepsilon_n,
 \qquad \varepsilon_n\downarrow0.                   \tag{2.4}
\]

After refining the subsequence, every \(B_i(\sigma^n)\) converges, and its
limit equals the corresponding marked linear functional of \(p\).

**Proof.**  Terminal rewards are bounded, hence the four cap sequences are
bounded.  Extract their limits.  The marked payoff never exceeds the cap;
(2.4) puts it within \(\varepsilon_n\).  Apply Theorem 2.1 and squeeze.
\(\square\)

The corollary is only numerical compactness.  The limit \(p\) is a generalized
order law, not automatically a product of four actual integer-valued stopping
laws.  Even an approximate realization preserving the displayed functionals
does not automatically upper-control the cap at unmarked clocks.

## 3. The tight executable subcategory

There is one elementary positive subcategory.

### Theorem 3.1 (calendar-tight marked limits are actual)

Assume the four marginal source laws are uniformly tight on
\(\mathbb N\cup\{\infty\}\) in total variation: for every \(\eta>0\), one
finite set \(K_\eta\subset\mathbb N\) satisfies

\[
 \sup_n\mu_i^n(\mathbb N\setminus K_\eta)<\eta
 \qquad(i\in I),                                    \tag{3.1}
\]

with the Never atoms retained separately.  Assume also that every marked
clock either stabilizes at a finite time, is identically Never after a
subsequence, or has a Late/Never payoff jump tending to zero against its
assigned opponents.

Then, after a subsequence, there is an actual product stopping-law profile
\(\sigma\), and actual finite/Never approximating marks, for which all
prescribed and marked payoff limits in Theorem 2.1 are realized to arbitrary
accuracy.  If the marks satisfy (2.4), the unrestricted caps converge as
well.

**Proof.**  Diagonal extraction on the countable atoms plus (3.1) gives
total-variation convergence of every marginal, retaining the Never atom.
Product coupling changes every terminal payoff, uniformly over the
deviator's own law, by at most the reward width times the sum of opponent
total-variation errors.  Thus prescribed payoffs and unrestricted caps are
continuous.  Stabilized finite/Never marks pass literally.  An escaping
finite mark differs from Never only by its Late/Never jump and a tie atom
which tends to zero, so the assumed vanishing jump gives the claimed
approximation.  \(\square\)

The theorem is the marked-order restatement of the existing executable tight
fusion boundary.  Under a positive global debt floor, the finite-deadline
escape-charge theorem forces exactly the excluded alternative: a marked
Late/Never jump bounded away from zero.

## 4. Why finite marked data is not response closure

One marked value does not control the rest of the obstacle function.  Here is
a literal two-clock regression embedded in Fin4.

Players 2 and 3 Never.  Player 0 also Never at the source.  In source `A`,
player 1 Quits at date 0 surely; in source `B`, player 1 Quits at date 1
surely.  Set player 0's only relevant rewards to

\[
 r_0(\{0\})=2,
 \qquad r_0(\{1\})=r_0(\{0,1\})=0,                  \tag{4.1}
\]

and set every other player's rewards to zero.

Both prescribed payoff vectors are zero.  At the single recorded mark
\(t=2\), player 0's replacement payoff is zero in both sources, with the same
coarse relation ``the opponent quit before the mark''.  Nevertheless

\[
 B_0(A)=0,
 \qquad B_0(B)=2,                                   \tag{4.2}
\]

because date 0 ties player 1 in `A` but strictly precedes player 1 in `B`.
Thus aggregating an opponent law into `before / tie / after / Never` at one
mark is insufficient.  The full order type in Theorem 2.1 distinguishes the
two sources only if the unmarked date 0 is itself retained as a test.

Adaptive near-cap marks repair (4.2) at the current source, as Corollary 2.2
says.  They do not repair response closure: after a marked complete update,
the other three cap-attaining clocks may change.  Iterating this repair is
exactly the finite tester tree, and the reviewed double-gap work proves that
pointwise tester coverage is not a full Nash-guard cover.

## 5. Exact no-go for a tight-translate bubble tree

The clock scale cannot be recovered from countably many positive-mass tight
translations alone.

### Proposition 5.1 (diffuse clock cloud)

For each `n`, let all four players independently choose a clock uniformly
from \(\{1,\ldots,n\}\), with no Never mass.  Then:

1. for every integer shift sequence \(a_n\) and every fixed \(R<\infty\),

   \[
   \mu_i^n([a_n-R,a_n+R])\le {2R+1\over n}\longrightarrow0; 
   \tag{5.1}
   \]

   hence no translated subsequence carries a nonzero tight probability
   profile;
2. absorption occurs surely for every `n`;
3. the probability that player \(i\) is the unique first quitter tends to
   \(1/4\); and
4. the probability of any tie at the first quitting date tends to zero.

Thus the terminal-coalition law converges to the law assigning mass \(1/4\)
to each singleton, although every additive tight-profile extraction is zero.

**Proof.**  Equation (5.1) is immediate from uniformity.  Since every clock is
finite, absorption is sure.  By symmetry it is enough to compute one unique
winner:

\[
 \Pr(i\text{ uniquely first})
 ={1\over n^4}\sum_{k=0}^{n-1}k^3
 ={(n-1)^2\over4n^2}\longrightarrow {1\over4}.       \tag{5.2}
\]

For any pair of players, the probability of equal clocks is \(1/n\).
A union bound over the six pairs bounds the probability of any tie, hence of
a tie at the minimum, by \(6/n\).  \(\square\)

This is not a game-theoretic counterexample; rewards have not been chosen.
It is an exact counterexample to a proposed compact-state grammar.  A valid
profile decomposition needs a **diffuse order layer** in addition to atomic
translated bubbles.  In the example, rescaling rank by `t/n` produces four
independent uniform variables on `[0,1]`, which records (5.2) exactly.

## 6. Exact finite source reprojection by common rank

The rank idea already gives an exact theorem before taking any limit.  Its
point is to use one order map for every port in a finite source diagram.

Fix a finite family of actual source profiles indexed by `p in P`.  List all
their finite marginal subprobability laws, with repetitions retained, as

\[
 \Lambda=(\lambda_1,\ldots,\lambda_N).
\]

Also fix a finite set `A` of marked deterministic clocks; discard its Never
marks from the finite list but retain their labels separately.  Put

\[
 C=N+|A|+1
\]

and define a probability measure on the finite calendar by

\[
 \nu={1\over C}\left(
   \sum_{k=1}^N\lambda_k
   +\sum_{a:\,t_a<\infty}\delta_{t_a}
   +w\delta_0\right),                                \tag{6.1}
\]

where

\[
 w=C-\sum_k\lambda_k(\mathbb N)-|\{a:t_a<\infty\}|>0.
\]

Every listed finite marginal satisfies \(\lambda_k\le C\nu\), and every
finite mark has \(\delta_{t_a}\le C\nu\).

For every date in the atomic support of \(\nu\), define its midpoint rank

\[
 R(t)=\nu(\{s:s<t\})+{1\over2}\nu(\{t\}).             \tag{6.2}
\]

Push every finite stopping mass and every finite marked clock through `R`;
keep Never as a separate isolated symbol.

### Theorem 6.1 (finite common-rank source reprojection)

The map `R` is strictly order preserving and injective on every date carrying
source or marked mass.  Applying it simultaneously to the finite family has
the following exact properties.

1. Every source profile has the same labelled terminal-coalition law and
   terminal payoff before and after reprojection.
2. Every marked complete-replacement payoff is unchanged.
3. If one listed source is obtained from another by a listed complete
   one-player replacement, their pushed profiles satisfy the identical
   replacement relation.  Thus source ancestry is preserved, not merely the
   two semantic endpoints.
4. A reference atom has a literal moat:

   \[
   \nu_R\!\left(
     (R(t)-\nu(t)/2,R(t)+\nu(t)/2)\setminus\{R(t)\}
   \right)=0,                                        \tag{6.3}
   \]

   where \(\nu_R=R_\#\nu\).  In particular a marked clock has moat radius at
   least \(1/(2C)\), and a source atom of mass `m` has moat radius at least
   \(m/(2C)\).

**Proof.**  If \(t<u\) are relevant dates, then

\[
 R(u)-R(t)
 ={\nu(t)\over2}+\nu(\{s:t<s<u\})+{\nu(u)\over2}>0.  \tag{6.4}
\]

Thus `R` preserves every strict order and every equality among clocks which
can occur with positive source probability or which is named by a mark.
First-quitter coalitions are therefore unchanged sample by sample.  This
proves assertions 1--2.  Since the same deterministic map is applied to
every port and every listed replacement law, coordinate replacement commutes
with pushforward, proving assertion 3.

The left and right endpoints in (6.3) are respectively the cumulative
reference mass strictly before `t` and weakly through `t`.  Every other
relevant rank lies outside that open interval by (6.4).  The domination and
mark bounds follow directly from (6.1).  \(\square\)

This theorem is finite but genuinely source-facing.  It does not identify a
cap vector with a source, and it does not rerank a successor independently.
It gives a common compact interval coordinate for every port of a supplied
finite executable diagram.

### 6.2 The two basic boundary tests pass

For Proposition 5.1, take the four uniform marginals and no response marks.
Apart from the harmless baseline atom, (6.2) sends the grid to an asymptotically
uniform grid in a fixed subinterval of `[0,1]`.  The pushed marginal laws
converge to a nonatomic rank law.  Hence the diffuse layer retains the four
strict-order probabilities in (5.2); no translated bubble is needed.

For the date-shift regression, include both moving dates \(k_n\) and
\(k_n+1\) among the source atoms or marks.  If their relevant masses are
bounded below, (6.4) separates their ranks by a fixed amount.  They cannot
collapse to a spurious tie.  If the masses vanish, every payoff contribution
requiring both events vanishes at the corresponding product scale.

A finite marked clock beyond the last source date is also separated by its
`1/(2C)` moat, while Never is kept outside the rank interval.  Thus the paid
Late/Never jump is retained rather than compactified away.

## 7. Revised nonlocal target: a dominated ordered-rank state

The terminal game is invariant under a common strictly increasing relabeling
of all finite dates.  This suggests replacing additive clock scales by order
rank.

For a profile and a finite list of marked response clocks, form one reference
measure from the four finite source marginals, fixed positive atoms at the
marks, and a harmless baseline atom.  Map every relevant finite date to the
midpoint of its cumulative reference-mass interval in `[0,1]`; keep Never as
an isolated point.  Then:

* all four pushed source laws are dominated by one reference law with a
  player-number-dependent density bound;
* every source atom of positive mass creates a rank interval of comparable
  width, so two order-one adjacent atoms cannot collapse into a spurious tie;
* atoms whose masses vanish may merge, but their possible tie contribution
  vanishes; and
* diffuse clouds such as Proposition 5.1 converge to nonatomic rank laws
  rather than disappearing.

Theorem 6.1 suggests the minimal compact datum for a fixed finite diagram:

\[
 \left(\nu_R,(R_\#\lambda_k)_{k\le N},
       (R(t_a))_{a\in A},\text{ isolated Never masses}\right). \tag{7.1}
\]

Its measures are commonly dominated, its positive atoms have moats, and all
ports use one coordinate system.  The precise infinite theorem target is:

### Theorem 7.1 (compact full-obstacle state for a fixed finite diagram)

There is an exact generalized compactification which already retains the
whole obstacle supremum.  Let

\[
 K_{\rm rank}=[0,1]\sqcup\{\mathsf{Never}\},
\]

with Never isolated, and let `M` bound all rewards in absolute value.  For a
source port `v` and player `i`, use its complete pure-time obstacle
\(V_{v,i}(t)\).  With the common rank map from Theorem 6.1, form the closed
hypograph

\[
\begin{aligned}
 \mathcal H_{v,i}:={}&\operatorname{cl}\{
   (R(t),y):t<\infty,\ -M\le y\le V_{v,i}(t)\}\\
 &\cup\{(\mathsf{Never},y):-M\le y\le V_{v,i}(\infty)\}.
\end{aligned}                                        \tag{7.2}
\]

Fix the combinatorial shape of a finite executable diagram: finitely many
source ports, literal complete-replacement edges, and marked response clocks.
For every sequence of actual realizations of that shape, apply one common
rank map to all its ports.  After a subsequence, the following converge
jointly:

1. every pushed marginal law, weakly on \(K_{\rm rank}\);
2. every labelled terminal-coalition law, in its finite simplex;
3. every marked rank and marked payoff; and
4. every \(\mathcal H_{v,i}\), in Hausdorff distance in the hyperspace of
   nonempty compact subsets of
   \(K_{\rm rank}\times[-M,M]\).

Literal replacement identities pass to the limiting pushed marginal laws.
Moreover

\[
 \lim_n B_i(\sigma_v^n)
 =\max\{y:(x,y)\in\mathcal H_{v,i}}.                 \tag{7.3}
\]

**Proof.**  The probability spaces in assertions 1--2 and the marked rank
intervals are compact metrizable.  The hyperspace of nonempty compact subsets
of a compact metric space is compact in the Hausdorff metric.  There are only
finitely many coordinates, so diagonal subsequence extraction gives all four
limits.  The same rank map is used at every port; hence equality of a replaced
marginal before the limit remains equality after pushforward and weak limit.

For each `n`, the largest second coordinate in (7.2) is exactly
\(\sup_tV_{v,i}^n(t)=B_i(\sigma_v^n)\).  Maximum of a continuous coordinate
function is continuous under Hausdorff convergence of nonempty compact sets,
which proves (7.3).  \(\square\)

The theorem gives a literal source-attached compact trace for any fixed
finite response program.  It also shows that obstacle-*supremum* compactness
is not the hard step once the whole closed hypograph is stored.  The hard
step is actualization: a Hausdorff-limit hypograph is an annotation unless it
is proved to be generated by the limiting pushed source law or supplied with
an executable diagonal recovery.

### Proposition 7.2 (ranked laws alone forget available cuts)

Atom moats and a diffuse rank layer still do not determine the obstacle.
Embed the following two-player construction in Fin4 by making players 2 and
3 Never.  Player 0 Never at the source.  In source `A`, player 1 uses

\[
 {1\over2}\delta_0+{1\over2}\delta_1;
\]

in source `B`, player 1 uses

\[
 {1\over2}\delta_0+{1\over2}\delta_2.                \tag{7.4}
\]

Set player 0's relevant rewards to

\[
 r_0(\{0\})=2,
 \qquad r_0(\{1\})=0,
 \qquad r_0(\{0,1\})=-3,                             \tag{7.5}
\]

and all other coordinates to zero.

If each source is canonically reranked using only its own marginal and the
same origin baseline, its pushed player-1 law consists of the same two atoms
of masses `1/2,1/2` at the same two ranks.  The prescribed payoff is zero in
both.  Nevertheless

\[
 B_0(A)=0,
 \qquad B_0(B)=1.                                    \tag{7.6}
\]

Indeed, in `A` the only distinct pure-time values are

```text
Q0=-1/2, Q1=-3/2, later/Never=0.
```

In `B`, date 1 is a genuine cut between the two opponent atoms and gives

```text
Q1=(1/2)*r_0({1})+(1/2)*r_0({0})=1,
```

while `Q0=-1/2`, `Q2=-3/2`, and later/Never is zero.

Thus a source-dependent order isomorphism may preserve every source atom and
tie while changing the set of available pure-time cuts.  A common rank for a
finite family distinguishes `A` and `B` by including all three dates.  The
regression shows why reranking a newly generated successor independently is
not a source-preserving renewal rule.  The hypographs (7.2), unlike the ranked
marginal laws alone, distinguish the two caps.

### Lemma 7.3 (uniform bounded variation of one obstacle)

Although the full obstacle carries more than the ranked laws, it has uniform
one-dimensional structure.  If rewards have absolute value at most `M`, then
for every source and player, the pure finite-time obstacle followed by Never
has total variation at most `5M`.

**Proof.**  Condition on the first opponent event `(s,S)`.  As the deviating
clock moves from before `s`, to equality at `s`, to after `s`, its payoff
contribution takes the three values

\[
 r_i(\{i\}),\qquad r_i(S\cup\{i\}),\qquad r_i(S).
\]

The two jumps have total size at most `4M`.  Weighting by all finite first
opponent events and summing gives at most `4M`.  On the event that all
opponents Never, every finite clock gives `r_i({i})` and Never gives zero;
the final jump contributes at most `M`.  Triangle inequality gives `5M`.
\(\square\)

Lemma 7.3 explains why the closed hypograph is a natural minimal annotation:
the obstacle cannot oscillate arbitrarily, but a single adjacency/tie spike
can still be strategically decisive, as Proposition 7.2 shows.

### The infinite theorem target

The exact conjecture-facing target is:

> **Dominated ordered-rank compactness.**  Construct a compact ordered cut
> space containing finite rank points, their left/tie/right evaluations, a
> diffuse part, Late, and isolated Never.  For every sequence of actual
> source profiles, extract jointly dominated rank laws such that terminal
> payoffs and the entire four pure-time obstacle functions converge in a
> topology which preserves their suprema.  Prove that every generalized
> terminal \(\varepsilon\)-Nash profile in this state has an actual
> integer-clock realization with terminal error at most \(C\varepsilon+o(1)\).

The source-dependent rank map must be applied simultaneously to the profile,
all selected responses, and every source update in the finite program.  This
is what prevents the source-component nonanchoring which survives in a mere
payoff/cap limit.

### Mandatory falsification tests

1. **Adjacent positive atoms.**  Two players put fixed positive masses at
   dates \(k_n\) and \(k_n+1\).  The compactification must preserve strict
   order, not turn it into a tie.
2. **Moving common atom.**  Two players share positive mass at \(k_n\).  The
   compactification must preserve the tie payoff.
3. **Diffuse cloud.**  Proposition 5.1 must produce the nonatomic rank layer
   and the four singleton probabilities.
4. **Paid Late/Never cylinder.**  A finite clock moving past a positive joint
   Never atom must remain distinct from Never and retain the exact jump
   \(r_i(\{i\})\Pr(M_{-i}=\infty)\).
5. **Obstacle supremum.**  A sequence of cap-attaining cuts may move between
   atoms.  The limiting full obstacle must contain that cut; convergence of
   finitely many marked values alone is insufficient.
6. **Source update.**  Replacing one player by a marked law and then taking
   another player's cap must use the pushed law of that literal updated
   source, not a separately reranked sibling.

Failure of any item is a sharp no-go for this compactification.  Passing the
first four only proves payoff continuity; items 5--6 are the conjecture-facing
producer fields.

### 7.3 The current minimal failure

The domination constant in Theorem 6.1 is proportional to the number of
listed marginal laws and marks.  It is uniform for a fixed finite program but
not for a growing response tree.  Assigning a fixed positive reference atom
to every possible pure time is impossible, and without such a weight an
unmarked cap-attaining cut can collapse into an atomic source date from the
wrong side.

This loss is already exact on a literal update path.  For `m>=1`, let
\(\sigma^k\), `0<=k<m`, be the four-player profile in which player 0 Quits
surely at date `k` and the other three players Never.  Consecutive ports obey

\[
 \sigma^{k+1}=\sigma^k[0\leftarrow\delta_{k+1}].      \tag{7.7}
\]

If one reference probability \(\nu\) dominates every displayed player-0 law
with a common constant \(C_0\), then

\[
 1\ge\sum_{k<m}\nu(\{k\})\ge {m\over C_0},
 \qquad\text{hence}\qquad C_0\ge m.                 \tag{7.8}
\]

Thus no fixed domination constant, and hence no fixed atom-moat scale derived
from domination, survives arbitrary renewal even along a single chain of
literal complete replacements.  For each finite `m`, Theorem 6.1 remains
exact; (7.8) rules out taking its constants uniformly in the path length.
All rewards may be set to zero, so this is a compact-state obstruction rather
than a positive-gap game.

Equivalently, finite source reprojection is exact, but the class (7.1) is not
yet a rectangular strategy space: its common reference rank depends on the
whole source family.  Reranking after a unilateral update destroys the
literal coordinate identity established in Theorem 6.1, while refusing to
rerank leaves no uniform domination for all future testers.  This is the
source-component nonanchoring obstruction in ordered-rank form.

The natural completion is a compact ordered **cut space** with distinct
left, tie, and right evaluations at every atom.  A finite collection of such
cuts is executable after applying a common increasing integer relabeling with
gaps.  What is not proved is sequential compactness of all obstacle
hypographs **as executable functions of the limiting law**.  Abstract
hypograph compactness and upper preservation of their suprema are Theorem
7.1; identifying the limit with one source law, uniformly through a renewable
update diagram, is the first unresolved theorem.

## 8. Local chart cocycles are Lipschitz but not sublinear

Let two actual sources differ only in player `p`'s stopping law, and let
\(\delta\) be the total-variation distance of those two laws.  Couple them so
that the two player-`p` clocks disagree with probability \(\delta\).  If
rewards have absolute value at most `M`, then

\[
 |U_i(\sigma)-U_i(\tau)|\le2M\delta                 \tag{8.1}
\]

for every player, under the convention that payoff difference is bounded by
`2M` times coupling failure.  For caps,

\[
 B_p(\sigma)=B_p(\tau),
 \qquad
 |B_j(\sigma)-B_j(\tau)|\le2M\delta\quad(j\ne p).   \tag{8.2}
\]

The equality holds because player `p`'s cap deletes its own source law.  The
inequality is uniform over player `j`'s deviating law, so taking a supremum
does not enlarge it.

If local reference measures use fixed weights and differ only through that
same marginal, their total-variation distance is at most the corresponding
reference weight times \(\delta\).  Their cumulative midpoint ranks therefore
move horizontally by at most a constant times \(\delta\).  Combining this
with (8.1)--(8.2) gives a Lipschitz transition between the two finite
hypograph charts.  Consequently **summable operational updates do give
summable chart seams**.

Neither Lemma 7.3 nor the atom moats improve this bound to little-oh of the
updated mass.  The following family makes the linear term exact while keeping
a fixed positive debt at both source ports.

### Proposition 8.1 (positive-debt paid adjacency seam)

Fix \(0<\varepsilon<3/5\).  Players 0 and 2 Never, and player 3 Quits surely
at date 2.  Define two sources by player 1's laws

\[
 \mu_1^A=(1-\varepsilon)\delta_0+\varepsilon\delta_1,
 \qquad
 \mu_1^B=(1-\varepsilon)\delta_0+\varepsilon\delta_2. \tag{8.3}
\]

The only nonzero rewards are

\[
\begin{array}{lll}
 r_0(\{0\})=2,&r_0(\{0,1\})=-3,&r_0(\{0,1,3\})=-3,\\
 r_1(\{1,3\})=2,&r_1(\{0,1\})=2,&\\
 r_2(\{2\})=2,&r_2(\{1,2\})=2.&
\end{array}                                          \tag{8.4}
\]

Every unlisted coordinate is zero.  Then:

\[
 U(A)=(0,0,0,0),
 \qquad
 U(B)=(0,2\varepsilon,0,0);                          \tag{8.5}
\]

the complete update \(A[1\leftarrow\mu_1^B]=B\) pays player 1 exactly
\(2\varepsilon\); and

\[
 B_0(A)=0,
 \qquad B_0(B)=2\varepsilon.                         \tag{8.6}
\]

At both sources player 2 has payoff zero and can obtain payoff 2 by Quitting
at date 0.  Hence

\[
 D(A)\ge2,
 \qquad D(B)\ge2,                                    \tag{8.7}
\]

uniformly as \(\varepsilon\downarrow0\).

**Proof.**  In source `A`, player 1 always Quits strictly before player 3, so
all prescribed rewards are zero.  In source `B`, the late
\(\varepsilon\)-branch ties players 1 and 3 and pays player 1 two.  This gives
(8.5) and the paid-update assertion.

For player 0 at `A`, the distinct finite-time values are

```text
Q0=-3+5*epsilon,  Q1=-3*epsilon,  later/Never=0.
```

Both displayed values are negative for the stated range.  At `B`, they are

```text
Q0=-3+5*epsilon, Q1=2*epsilon,
Q2=-3*epsilon, later/Never=0.
```

This proves (8.6).  Finally, player 2's Q0 payoff is two on both the early
branch, where it ties player 1, and the late branch, where it Quits alone
before the others.  Its prescribed payoff is zero, proving (8.7).
\(\square\)

The moved stopping mass has total variation \(\varepsilon\).  Both the paid
gain and the new cap seam are exactly \(2\varepsilon\).  Thus a sequence of
such source-attached transitions with nonsummable paid masses has
nonsummable chart seam.  The fixed positive debt (8.7) shows that this is not
an artifact of approaching a zero-debt source, although the displayed table
has not been claimed to have a positive **global** minimum debt.

### Corollary 8.2 (a closed paid loop defeats a monotone chart toll)

Keep the table in (8.4).  In addition to `A,B`, define

\[
 C=B[0\leftarrow\delta_1],
 \qquad
 D=C[1\leftarrow\mu_1^A].                            \tag{8.8}
\]

Then the four literal complete-update edges

\[
 A\xrightarrow{1}B\xrightarrow{0}C
  \xrightarrow{1}D\xrightarrow{0}A                 \tag{8.9}
\]

are all strictly profitable to the displayed updater.  Their gains are,
respectively,

\[
 2\varepsilon,quad2\varepsilon,quad
 2\varepsilon,quad3\varepsilon.                    \tag{8.10}
\]

Every port has total debt at least two.

**Proof.**  The first edge is Proposition 8.1.  At `B`, player 0's Q1 value
is \(2\varepsilon\), giving the second edge.  At `C`, the early branch is
still won by player 1 at date 0, while on the late branch changing player 1
back to \(\mu_1^A\) ties player 0 at date 1 and earns
\(r_1(\{0,1\})=2\); this gives the third gain.  At `D`, player 0's prescribed
payoff is \(-3\varepsilon\), while returning to Never recreates `A` and
gives zero, proving the fourth.  Player 2's Q0 payoff remains two at every
port, exactly as in Proposition 8.1.  \(\square\)

Consequently no scalar chart potential can decrease by a fixed positive
multiple of every paid-update gain: summing such inequalities around (8.9)
would give `0<0`.  This loop is used only to falsify a monotone cocycle toll.
It is not a Nash--Bellman carrier, an executable chronological cycle, or a
counterexample to uniform equilibrium.  Its global minimum debt may be zero.

### Cocycle verdict

Local common-rank charts have an exact Lipschitz cocycle on every finite
actual update diagram.  This consumes the branch where the total operational
variation of all updates is summable.  Bounded variation of the obstacle does
not turn a nonsummable paid update stream into a summable or `o(charge)` seam:
Proposition 8.1 has a first-order adjacency spike with the same scale as the
paid transition.

A successful renewable cocycle therefore needs additional cancellation tied
to a **Nash--Bellman or essential-component** return, not merely a closed
chain of paid responses.  Neither the `5M` variation bound nor positive debt
at each visited source supplies that identity.  This is the exact stopping
point for the local-chart route; enlarging the state again would only record
the same linear seam.

## 9. Evidence and nonclaims

Theorems 2.1, 3.1, 6.1, and 7.1 and Proposition 5.1 are proved above in ordinary
mathematics.  The dominated ordered-rank compactness statement is not proved.
In particular, this note does not establish upper semicontinuity of the full
obstacle supremum, a Nash equilibrium in the generalized rank game, an
essential-component degree transfer, or an actual terminal approximate Nash
profile.

The regression does not contradict the split Late/Never architecture; it
shows that split infinity is only the first boundary layer.  It also does not
revive universal exact periodicity.  A diffuse or growing-rank realization is
explicitly allowed.

## 11. Next exact question

The remaining nonlocal question is whether an essential equilibrium component
or an actual Nash--Bellman charged return supplies a signed holonomy
cancellation absent from arbitrary response loops such as (8.9).  Concretely:
does the equilibrium-component degree orient the obstacle jumps so that their
player-deleted reach-weighted sum vanishes?  A positive answer would make
chart seams telescope.  A negative answer must respect the full component or
Nash--Bellman fields; Corollary 8.2 shows that another unrestricted-response
cycle is not informative.
