## 3. The punishment vector is a conditional reservation

### Lemma 3.1

For every root sequence `roots`, the vector

```text
P_i = quittingPunishmentValue reward i
```

satisfies

```text
IsQuittingConditionalReservation reward roots P.
```

### Proof

Fix a player `i`, a suffix starting at `s`, and `zeta>0`.  Let `profile_s` be
the literal behavioral profile generated by that suffix.  By definition,

```text
P_i = inf_profile quittingBestReplyValue reward profile i,
```

so the checked inequality `quittingPunishmentValue_le` gives

```text
P_i <= quittingBestReplyValue reward profile_s i.
```

The best-reply value is a supremum over unrestricted behavioral strategies.
By the defining approximation property of a bounded nonempty supremum, there
is a behavioral response against `profile_s` whose payoff is at least
`P_i-zeta`.  Along the unique live history this response is exactly a hazard
sequence.  This is the required tail in
`IsQuittingConditionalReservation`.  No best response is assumed attained.

## 4. Every uniformly reached row is exact against its floor lift

### Theorem 4.1 (reached-row punishment-floor lift)

For every `row` as in Section 1, equation (1.1) holds.

### Proof

For the `n`th source selected by the row's nested subsequence, put

```text
index_n = base.index (row.subsequence n),
source_n = landing.family.source index_n,
t_n = source_n.crossingStage + row.offset,
s_n = quittingJointSurvivalWeight source_n.roots 0 t_n.
```

The row field `reached` supplies one constant `r>0` with `r<s_n` for every
`n`.  Apply the checked theorem
`isεQuittingRootNash_quittingLiftedContinuation` to `source_n.sourceNash`,
stage `t_n`, and the conditional reservation `P` from Lemma 3.1.  It gives

```text
IsQuittingRootNash reward L_n (accuracy_n/s_n)
  (source_n.roots t_n),                              (4.1)
```

where

```text
L_n(i) = max
  (quittingRootSequenceTailVector reward source_n.roots (t_n+1) i)
  P_i.
```

This use of the source Nash inequality is the decisive point.  A deviator may
Continue at `t_n` and then use an unrestricted response securing `P_i` against
the actual opponent suffix.  Its conditional gain is divided only by the
probability `s_n` of reaching the current row.  It is **not** divided by the
prescribed probability that the deviator itself Continues at that row.

Along the same subsequence:

1. `accuracy_n -> 0`, because the composed source index tends to infinity;
2. `s_n>=r`, hence `accuracy_n/s_n -> 0`;
3. `source_n.roots t_n -> q`, by `row.root_tendsto`; and
4. the actual next-tail vector tends to `T`, by
   `row.nextValue_tendsto`.

Coordinatewise maximum with the fixed vector `P` is continuous, so
`L_n -> T^P`.  Root expected payoff is a finite polynomial in the product
root probabilities and affine in the continuation vector.  Passing each
inequality in (4.1) to the limit therefore gives

```text
IsQuittingRootNash reward T^P 0 q.
```

Equivalently one may pass through the closed graph of exact endpoint Nash
after using the checked root-Nash/endpoint-Nash equivalence.  This proves
(1.1).  Notice that neither `row.currentValue` nor reach of the *next* row is
needed.

### Proof

This argument works with one or several sure quitters.  It supersedes the

## 7. Boundary and regression audit

The scalar regression in Ramsey's note takes a sure owner `k`, a next tail
`T_k<P_k`, and a root for which Quit and Continue are tied at `T`.  Raising
the tail to `P_k` then makes Continue strictly better.  This correctly shows
that **exact endpoint Nash at the raw tail plus rationality of the current
value** does not preserve Nash under floor clipping.

It does not falsify Theorem 4.1.  If that row were a uniformly reached limit
of the maintained unrestricted approximate-equilibrium sources, the deviator
which Continues and then best-responds would force the clipped endpoint
inequality in the opposite direction.  Thus the regression identifies
exactly which field was missing: conditional-reservation control inherited
from the source Nash profile at positive reach.

At zero current-row reach the theorem is false in general, because the source
Nash error cannot be conditioned.  At positive but nonuniform reach the ratio
`accuracy/survival` need not vanish.  The fixed `row.reachFloor>0` is therefore
essential.
