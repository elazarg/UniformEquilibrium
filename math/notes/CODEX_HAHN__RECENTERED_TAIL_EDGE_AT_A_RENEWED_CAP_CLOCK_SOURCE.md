# The recentered tail edge starts at a renewed cap-clock source

Author: CODEX_HAHN

## Status

**Exact source-correspondence audit; ordinary mathematics, not Lean-checked,
and not a renewable transition.**  In the maintained capacity-gap
construction, the literal old tail \(X_n\) in the vanishing-live-word
recentring theorem is not an arbitrary profile.  It is the actual high reset
child from the renewed singleton-wall construction.  Hence the new fixed-gain
tail response begins at an existing cap-clock seed.  Its target is not proved
to retain that seed.

## 1. Literal identification

The renewed two-sided singleton-wall adapter defines its high side by
\[
 X_n=\operatorname{Sem}(S_{m_n+1}),
\tag{1}
\]
where \(S_{m_n+1}\) is an actual sufficiently late reset child.  The
capacity root-matching construction forms literal finite words
\[
 q_{n,K-1}\triangleright\cdots\triangleright q_{n,0}
 \triangleright S_{m_n+1}.
\tag{2}
\]
Every matching step prefixes one exact root.  It never changes the bottom
tail in (2).  The subsequent unique-sure diagonal writes that same object as
\[
 \Sigma_n=W_n\triangleright X_n.
\tag{3}
\]
Thus the \(X_n\) in (3) is literally the actual high reset child in (1), not
merely a profile with the same semantic pair.

## 2. Fields retained at the source

The late-reset theorem supplies at \(X_n\), for one fixed reset observer
\(b\):

1. an actual behavioral source profile;
2. an attained Quit0 complete cap for \(b\);
3. a uniform positive \(b\)-debt floor;
4. a cap coordinate uniformly close to \(r_b(\{b\})\); and
5. the game-level no-uniform-payoff and bounded exact-block-capacity inputs.

These are exactly the fields needed to start the positive-survival
escaping-cap-clock construction again from \(X_n\).

The vanishing-live-word recentering theorem supplies, for the unique-sure host
\(k\), an actual tail update
\[
 Z_n=X_n[k\leftarrow\zeta_{n,k}],
\qquad
 U_k(Z_n)-U_k(X_n)\ge D_*/4,
\qquad
 d_k(Z_n)\longrightarrow0.
\tag{4}
\]
Therefore (4) is a fixed-gain paid edge whose source already carries the
renewed cap-clock seed.

## 3. Exact boundary

This is not a source-to-source renewal theorem.  Updating player \(k\) can
change the reset observer \(b\)'s payoff and unrestricted cap.  Nothing
proved here shows that Quit0 still attains \(b\)'s cap at \(Z_n\), that
\(d_b(Z_n)\) retains its floor, or that \(Z_n\) carries a new singleton wall.

The maintained construction also does not attach to \(X_n\) a complete
global-minimum producer, a retained positive terminal atom, or stationarity.
Those fields cannot be inferred from its being an actual high reset child.

Consequently the exact strengthened interface is
\[
 \boxed{\text{renewed cap-clock source}
 \ \dashrightarrow_k\
 \text{fixed-gain nearly cap-attaining actual target},}
\tag{5}
\]
not a renewable cap-clock transition.  A consumer must either preserve or
reconstruct the source seed at \(Z_n\), or close the paid edge by a return or
well-founded rank.
