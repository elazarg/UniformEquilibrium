# Historical resolution: the Fin4 quantitative tail-escape leaf

## Resolution

Quantitative tail escape is not an independent mathematical leaf.  For a
nonsingleton minimum-law atom of mass `mu`, choose one sufficiently late
actual selected profile `sigma` and its marked date `t`, and copy the literal
roots of `sigma` through `t` before restarting the complete profile `sigma`.
This self-tail closure preserves the marked atom exactly and makes its
post-date continuation literally `sigma`.  Since `D(sigma) -> D_*`, the raw
low-tail same-stage dispatch applies.  Closed monodromy is impossible, so the
result is a source-attached strong concentrated-singleton packet.

Thus every nonsingleton minimum-law source enters the same concentrated-
singleton obligation as the singleton minimum-law source.  The checked chain
is packaged by `FinFourMinimumAtomProducer.nonempty_nonsingletonSelfTailConsumption`
and the common contracted-consumer structures in
`Research/Quitting/FinFourProducerAtlas/SelfTailContraction.lean`.  The
material below records the former question and must not be treated as a live
consumer obligation.

## Objective

Turn every `TailEscapeSubsequence` returned by the Fin4 atlas into a causal
near-return, terminal approximation, or source-preserving well-founded
descent.

## Checked entrance

The tail-escape leaf retains one fixed nonsingleton minimum-law atom and a
strict subsequence of its actual causal selected rows.  Writing

```text
mu = selected minimum-law atom mass,
D_* = positive global minimum total debt,
lambda = mu^2 / 8,
h = mu^2 * D_* / 16,
```

every selected rank has:

```text
stageMass > lambda,
D(actual shifted tail) - D_* >= h.
```

The profiles, exact cap-prefix stacks, marked dates, selected tail profiles,
and source atom remain attached to the subsequence.

## Exact checked return account

For a supplied exact cap-Nash root against an escaped tail:

```text
D(prefixed tail)
  = D(tail) - D(tail) * rootAbsorption.
```

The prefix returns within a prescribed minimum-debt tolerance exactly when
its absorption charge spends all but that tolerance of the tail excess.

The marked collision atom occurs immediately **before** this escaped tail.
It is therefore not automatically an atom of the continuation to which the
return root is prefixed.  A return construction may retain an atom already
inside its supplied continuation, but it may not claim to retain the marked
pre-tail atom without a separate later-atom theorem.

Maximal-absorption selection sharpens the local alternative to:

1. a spending return root; or
2. universal same-tail undercharge, possibly with all-Continue exact and
   fixing the escaped tail.

Thus existence or maximization of an exact root is not the missing step.

## Exact remaining theorem

Prove, on the retained actual subsequence,

```text
TailEscapeSubsequence reward minimum atom
  -> positive cumulative admissible payoff near-return
     or terminal epsilon-Nash profiles for every epsilon > 0
     or source-preserving well-founded atlas descent.
```

Equivalently, consume universal same-tail undercharge and the lossless
all-Continue stall by changing state in a controlled, source-matched way, or
show that repeated undercharge regenerates a strictly smaller atlas node.

## Acceptable answers

1. construct absorption-spending exact roots on a cofinal source-matched
   subsequence and feed them to an existing near-return compiler, with every
   required continuation atom produced at the correct tail state;
2. consume the undercharged/inert branch directly into terminal approximants;
3. construct a regenerated finite-rank descent retaining the causal atom and
   all data needed to repeat; or
4. construct an actual all-behavior positive-gap Fin4 table satisfying the
   complete tail-escape leaf.

## Outputs that do not answer the question

- selecting a maximal root and returning its existing undercharge split;
- asserting that a positive suffix atom is current root absorption;
- transporting the marked pre-tail collision atom through a root attached
  only to the escaped post-row continuation;
- a strict real debt decrease without an actual regenerated source;
- a cap port whose displacement or absorption scale may vanish on restart;
- replacing the escaped tail by a semantically equivalent carrier point; or
- bounded-time or stationary-only deviation estimates.
