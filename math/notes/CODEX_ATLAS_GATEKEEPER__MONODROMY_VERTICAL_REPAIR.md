## 6. Boundary tests for any proposed repair

Any claimed vertical repair must pass all of the following.

1. **Past-cap test.**  Changing the marked root may change best responses at

\]

## 9. Exact past-cap instability with a low tail and paid square

The past-cap seam is not only a logical warning.  It occurs in an exact
two-stage Fin4 profile while the post-date tail is a global zero-debt minimum,
the marked square has fixed positive reach, the square source is paid, and the
copied past root is exact cap--Nash for the original source.

This regression does not satisfy a positive global minimum, so it does not
refute the desired hard-residual theorem.  It proves that positive-minimum
provenance must do genuine work: low post-date debt, response curvature,
payment, and source-prefix exactness alone cannot yield past-cap stability.

### Table

Write the players as `h=0`, `k=1`, `i=2`, and `j=3`.  Put `r_k=0`
everywhere.  For `i,j`, set rewards to zero unless the coalition contains the
base `{h,k}`.  On coalitions containing that base, put

\[
r_i(S)=\mathbf 1_{\{\mathbf 1_{i\in S}\ne\mathbf 1_{j\in S}\}},
\qquad
r_j(S)=\mathbf 1_{\{\mathbf 1_{i\in S}=\mathbf 1_{j\in S}\}}.
\tag{30}
\]

For `h`, put

\[
r_h(\{k,i\})=1
\]

and zero on every other nonempty coalition.  In particular every singleton
reward is zero.  Hence the all-Never profile is an exact terminal Nash profile
and the global literal minimum debt is zero.

Let

\[
A=\{h,k\},\quad Ai=\{h,k,i\},\quad
Aij=\{h,k,i,j\},\quad Aj=\{h,k,j\}.
\]

At a pure marked root, (30) gives the strict square

\[
A\xrightarrow{i}Ai\xrightarrow{j}Aij
\xrightarrow{i}Aj\xrightarrow{j}A,
\tag{31}
\]

with table gain one on every edge.  The `i` response difference between Quit
and Continue is `+1` when `j` Continues and `-1` when `j` Quits, so the table
response cross-difference has magnitude two.

### Literal profiles

At date zero use the product root `q` at which `h` Quits with probability
`1/2` and every other player Continues surely.  Conditional on all Continue,
at date one prescribe one of the four pure coalitions above.  After date one,
all players Continue forever.  Call the resulting profiles
`sigma_A`, `sigma_Ai`, `sigma_Aij`, and `sigma_Aj`.

Their complete past is identical, their complete post-date tail is all Never,
and their date-one coalition mass is exactly `1/2`.  Consequently every edge
of (31) has actual payoff gain exactly `1/2`, and the actual response
cross-difference has magnitude one.  At `sigma_A`, player `i`'s deviation to
Quit at date one rather than Never is a literal paid row of gain `1/2`.

The post-date all-Never tail has total debt zero, exactly the global minimum.

### The source prefix is exact

For the date-one suffix with coalition `A`, the behavioral cap vector is

\[
B(A)=(0,0,1,1).
\]

Against this continuation vector, `q` is an exact product Nash root:

- `h` is indifferent between its zero singleton reward and continuation cap
  zero;
- `k` is identically indifferent;
- `i` and `j` weakly prefer Continue, which yields their continuation cap on
  the event that `h` Continues, to their zero date-zero Quit payoff.

Thus the copied date-zero row has precisely the source-side cap--Nash
certificate one would like to transport.

The complete source profile has

\[
U(\sigma_A)=(0,0,0,1/2),
\qquad
d(\sigma_A)=(0,0,1/2,0).
\tag{32}
\]

### One endpoint update destroys exactness

Replace only the date-one root by `Ai`.  At this suffix, if `h` Continues at
the marked row, players `k` and `i` Quit and the terminal coalition is
`{k,i}`, paying `h` one.  If `h` Quits, its payoff is
`r_h(Ai)=0`.  Therefore

\[
B_h(Ai)=1.
\]

At the copied date-zero root, `h` is still prescribed to Quit with probability
`1/2`.  Quit pays zero while Continue reaches cap one.  The old root `q` is
therefore not Nash against `B(Ai)`; its `h`-coordinate root defect is exactly
`1/2`.

For the resulting complete sibling,

\[
U(\sigma_{Ai})=(0,0,1/2,0),
\qquad
d_h(\sigma_{Ai})=1,
\qquad d_j(\sigma_{Ai})=1/2.
\tag{33}
\]

The extra `h` debt is the past-cap witness switch.  It is not visible in the
common post-date tail or in the horizontal mover identity.
