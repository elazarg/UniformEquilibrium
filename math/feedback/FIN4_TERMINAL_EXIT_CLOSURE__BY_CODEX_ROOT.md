# Review of Fin4 renewable terminal-exit closure

## Verdict

The renewable source/rank result in `RESPONSE.md` remains genuine. The new
`FIN4_TERMINAL_EXIT_CLOSURE.md` does **not** yet close the three terminal exits.
It contains a plausible scale-sensitive reduction of the first two exits to a
paid response packet, but Section 5 assumes the missing chronology producer.

In particular, the document does not construct a
`QuittingPositiveCumulativeAdmissiblePayoffNearReturnFamily`. Its claim of a
complete ordinary-mathematics closure is presently unsupported.

## Claim reviewed

After enriching each renewed node by a source-attached tangent passport, the
document proposes:

```text
positive tangent slope
or flat support entry
or paid first disagreement
  -> source-attached paid first disagreement
  -> positive cumulative punishment-floor admissible near-return
  -> uniform-equilibrium payoff.
```

The last implication is decisive.

## Valuable part

The proposed node repair is mathematically appropriate. Equality of semantic
base points does not identify literal profile sequences, deleted laws, tangent
scales, or causal rows. A source-attached tangent passport is the correct data
to retain.

The normalized cap-chord quantity

```text
kappa_i(n) = (B_i(x_n) + B_i(y_n) - 2 B_i(h_n)) / a_n
```

is also the right scale. The already reviewed minimum-fibre common-response
compiler proves only an unscaled error tending to zero. It does not imply an
`o(a_n)` error.

Subject to constructing the literal passport and handling subsequences, the
following algebra is plausible:

- if `kappa_i -> 0`, an `o(a_n)`-best response at the half profile is
  `o(a_n)`-optimal at both endpoints;
- if `kappa_i` stays positive, endpoint responses yield a positive normalized
  response-square premium; and
- a positive tangent coordinate converts the scale-sensitive common-response
  arm into a positive response contrast.

For the positive-total-slope arm, the selected positive coordinate must be
proved to be a nonmover, since the common-response construction is only for
nonmovers. This should follow from exact annihilation of the active mover's
debt, but it is not stated in the proof.

The passage from a response square to one finite paid first-disagreement row
also requires an actual theorem. A complete behavioral response can use
infinite support or Never, and its positive expected contrast may diffuse or
escape rather than localize at one finite row with the required normalized
floor.

## Decisive gap in Section 5

`QuittingSourceFaithfulMinimumCausalization` supplies:

- the same literal suffix profiles and marked dates;
- arbitrarily deep exact cap--Nash prefix stacks;
- debt scaling and survival tending to one;
- retained marked mass; and
- exact multiplicative transport of a supplied behavioral-response contrast
  through the new common prefix.

It does not supply:

- floor-admissible boxed states;
- `IsQuittingNashBellmanEdge` edges between prescribed payoff vectors;
- a path in `quittingPunishmentFloorAdmissibleChargedRelation`;
- an exact entrance/successor seam between successive paid rows; or
- recurrence of the path endpoints.

This distinction is structural. A paid first-disagreement row is a profitable
deviation or response contrast. Its source root need not be an exact Nash root.
An edge of the target admissible relation, by definition, contains an exact
`IsQuittingNashBellmanEdge`. Adding an exact cap--Nash prefix before the paid
row does not turn that paid row into such an edge.

The estimates asserted in Section 5,

```text
paid_n >= (3g/4) a_n,
returnError_n / a_n -> 0,
admissibilityError_n / a_n -> 0,
```

therefore do not themselves construct the exact path demanded by
`QuittingPositiveCumulativeAdmissiblePayoffNearReturnFamily`.

There is a second missing quantitative step. The near-return structure asks
for one fixed positive lower bound on `path.chargeSum`, where charge is literal
root absorption. A payoff premium of order `a_n` is neither root absorption
nor a fixed charge floor. Repeating approximately `1/a_n` local blocks would
require exact compatible seams and an ordered concatenation theorem; those are
precisely what has not been produced.

Allowing different responses and caps at different ranks does not resolve
this. The issue is not cross-rank response coherence. It is exact
Nash--Bellman chronology and fixed cumulative absorption charge.

## Strongest honest output

The document identifies a useful new intermediate target:

```text
source-attached tangent passport
  -> scale-sensitive common response
     or normalized paid response square.
```

If the first-disagreement localization is proved, the three terminal exits may
reduce to a single source-attached paid packet. The remaining theorem is still

```text
source-attached normalized paid packet
  -> exact positive cumulative punishment-floor admissible near-return.
```

That is a version of the existing chronological debt-shadowing/paid-row
consumer problem, not a consequence of source-faithful causalization already
in the repository.
