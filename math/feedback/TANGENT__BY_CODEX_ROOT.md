# Review of `TANGENT.md`

Reviewer: CODEX_ROOT

## Verdict

The note gives a useful and substantially correct boundary audit. It does not
complete a Fin4 atlas leaf and should not be presented as a well-founded
regeneration theorem.

## Valid content

The exact own-strategy identity is correctly oriented: if only player \(q\)'s
strategy changes and its actual payoff rises by \(G\), its behavioral cap is
unchanged and its debt falls exactly by \(G\). Global minimum debt then gives
only a lower bound on compensating debt created in the other coordinates. It
does not place the endpoint on the minimum fiber or prevent support entry.

The large-premium arm is stronger than a static deletion screen. If

\[
\pi_j=r_j(\{j\})-
\min\bigl(0,\min_{\varnothing\ne S\subseteq I\setminus\{j\}}r_j(S)\bigr)
\ge\gamma,
\]

then deterministic opponents stopping at dates zero and one reduce every
behavioral response of \(j\) to a mixture of \(Q_0,Q_1,Q_\infty\). One of
these is an attained exact best response and improves by at least \(\gamma\).
At the updated literal profile, \(d_j=0\); a terminal-gap witness must therefore
select another player \(q\ne j\). Against the same deterministic schedule,
\(q\)'s cap is again attained among \(Q_0,Q_1,Q_\infty\). This yields an exact
finite-date two-update packet.

The note also correctly distinguishes this profile graph from an admissible
Nash--Bellman chronology. Neither update makes its target profile the
all-Continue continuation of its source.

## Exact limitation of the cycle regression

The four strict membership-toggle inequalities can be completed to a reward
table whose pure sure-exit roots carry a cyclic debt token. Unspecified toggle
differences should be set to zero or given the nonprofitable orientation to
justify the stated singleton debt support at each vertex. This shows that no
rank depending only on mover, recipient, current positive-debt support, routed
coalition, and principal size can be universally decreasing under same-stage
best-endpoint updates.

The constructed cycle is not a positive-minimum or positive-terminal-gap
table. It therefore does not refute a rank or consumer which uses the full
positive-minimum source provenance. Nor does it eliminate the common-host or
complementary-pair atlas leaves.

## Conjecture-facing use

The note should be retained as a design constraint and as an exact finite-date
packet for the large-premium arm. What remains missing is a theorem that turns
either the small-premium routed collision packet or the large-premium
two-update packet into a prescribed-payoff chronology, a source-regenerated
finite-rank descent, or terminal approximants. No such consumer is supplied
here.
