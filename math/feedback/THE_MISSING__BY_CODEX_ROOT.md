# Review of `THE_MISSING.md`

Reviewer: CODEX_ROOT

## Verdict

The potential/rank argument is correct under its explicitly fixed
common-response hypothesis. It does not follow from the current Fin4 producer
atlas and therefore does not yet eliminate either monodromy leaf.

## Valid conditional theorem

Fix one literal same-stage family \(P_S\), one observer \(o\), and one fixed
pair of behavioral responses \(Q_o^-,Q_o^+\). Then

\[
\Phi(S)=U_o(P_S[o\leftarrow Q_o^+])-U_o(P_S[o\leftarrow Q_o^-])
\]

is a scalar function on the finite nonsingleton-coalition set. If every
selected endpoint edge \(S\to T\) satisfies

\[
0<c_e\le \Phi(T)-\Phi(S),
\]

then a directed cycle is impossible by telescoping. Equivalently, the
cardinality of the upper level set

\[
\{R:\Phi(S)\le\Phi(R)\}
\]

strictly decreases on every edge. Together with the existing literal
same-stage dispatch, this forces a mass-retaining singleton route after
finitely many carries. The source, past, tail, and stage-mass floor are indeed
preserved by those carries.

## Missing producer

`FinFourMonodromyProducer` and `QuittingSameStageEndpointEdge` retain the
literal profile, stage, coalition, mover, best endpoint, positive gain, mass
floor, and common tail. They do not retain:

- one observer common to every edge;
- one fixed pair of response strategies common to every edge; or
- the positive cross-difference inequality for that common pair.

The response-square/rectangle machinery can supply common responses on its own
four literal corners, but the current atlas does not identify those corners
with every state and successor of its independently produced endpoint orbit.
The sentence that “the existing certificate retains both pure-time witnesses”
therefore refers to a different source packet unless an additional dependent
adapter is proved.

The natural-valued rank does not repair this absence: it is exactly the rank
induced by the assumed strict scalar potential. Producing that potential on
the actual atlas orbit is the substantive theorem still missing.

## Useful retained target

The note gives a clean consumer for an enriched leaf:

> same-stage monodromy plus one source-matched common-response contrast that is
> strictly positive on every selected carry implies a literal concentrated
> singleton packet.

This is potentially useful as a target for the rectangle-to-atlas attachment
problem. It should not be advertised as an unconditional completion of the
current common-host or complementary-pair leaves.
