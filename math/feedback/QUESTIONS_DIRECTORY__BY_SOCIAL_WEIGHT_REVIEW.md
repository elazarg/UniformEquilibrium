# Independent audit of the open-question directory

Reviewer: `SOCIAL_WEIGHT_REVIEW`

Verdict: **REVISE**

I checked every question against the mathematical frontier, the checked
declarations named there, the formalized packets, and the current exports.  The
directory still covers the important live routes.  It does not contain a
question whose requested terminal conclusion has already been proved.  It does,
however, contain one materially stale source specification, one malformed and
poorly aligned clock question, one obsolete specialized search normal form, and
one avoidable umbrella duplication.

The canonical terminal classification should remain simple:

1. a positive global minimum in the full-debt chamber; or
2. a positive global minimum in the reset-rigid chamber.

Everything else in `questions/` is a possible consumer, sufficient route,
source adapter, or refutation program inside or alongside those two chambers.
It should not be counted as an additional terminal chamber or SCC.

## Exact actions

### 1. Rewrite the postmark two-cut question

`FIN4_POST_MARK_TWO_CUT_RENEWABLE_CHILD_SOURCE.md` uses an older formulation.
In particular, its paid arm says that the whole replacement target has
`d_p(y_n) -> 0`.  The two-cut splice gives a small payer debt for the **updated
entry suffix**, while the whole-parent payer debt is only known to decrease by
the exact whole-profile gain.  Those statements are not interchangeable.

The replacement question should start with the following supplied data, in
ordinary mathematical language.

- Actual restart profiles `s_n` have joint semantic/law limit `(z_*, nu)`,
  where `D(z_*)=D_*>0` is globally minimal.
- One finite coalition `A` has limiting law mass `mu>0`.
- Prefix one terminally silent all-Continue row.  Use entry cut `1`, and choose
  a finite exit cut so that the literal block in `s_n` contains hazard at least
  a fixed `chi`, for example `mu/2`.  Entry reach is exactly one.
- Put `K=(1-exp(-chi))D_*` and
  `delta=((exp(chi)-1)/2)D_*`.  The exhaustive output is either
  `D(exit suffix) >= D_*+delta`, or one fixed payer with entry debt `>K/8`
  and an actual replacement whose entry-suffix gain is `>K/16`, whose updated
  entry-suffix payer debt is `<=K/16`, and whose whole padded-parent debt drops
  by its exact whole-profile gain.

The question should ask only for consumption of the off-minimum exit or the
paid parent/entry target, including renewable child reconstruction if needed.
It must retain the warning that the silent mark is artificial and that
reattachment behind the earlier sure-quitting pair has zero outer reach.  The
finite-window producer itself is no longer an open question.

### 2. Replace the Jensen/clock file by a response-switch question

`FIN4_JENSEN_CLOCK_SELECTION_AND_CAP_LEAKAGE.md` has broken mathematical
transcription (`\to`, `\ge`, and display delimiters have been lost), and its two
residuals mix older screened-tail and fixed-tail-ray descriptions already
covered by the uniform-escape and paid-cap questions.

The useful unresolved content is narrower: a source-attached response
rectangle has one paid replacement, one different coordinate whose cap/debt
rises, and a common pure-time response giving a fixed positive mixed response
curl.  A bounded response time should produce a finite executable witness; an
escaping response time should produce a genuine clock/tail packet.  Neither
branch is currently consumed.

I recommend replacing the file, preferably under a title such as
`FIN4_RESPONSE_CURL_OR_ESCAPING_CLOCK_CONSUMER.md`, by a self-contained
question with four actual profile families `P_n,Y_n,Q_n,R_n` satisfying:

- `Y_n` differs from `P_n` only by a fixed payer's complete response, with a
  fixed positive gain and exact own-debt subtraction;
- a fixed other player `j` has a positive cross-coordinate cap/debt rise;
- `R_n` and `Q_n` use the same pure-time response of `j` against `Y_n` and
  `P_n`, respectively;
- `d_j(R_n) -> 0`; and
- the alternating response gain
  `(U_j(R_n)-U_j(Y_n))-(U_j(Q_n)-U_j(P_n))` has one fixed positive lower
  bound.

The question should consume the bounded-time or escaping-time alternative
into a terminal equilibrium, charged return, renewable finite rank, or an
exact counterexample.  This is the clean place to ask about the surviving
cap-switch/clock bubble.  It should not be stated as another named atlas node.

### 3. Remove or completely retarget the strict-inert specialized search

`FIN4_INERT_MACHINE_CERTIFICATE_SEARCH.md` encodes an older strict
normalized-inert local normal form and itself concedes that counterexamples in
other branches may remain.  The general escape-aware exact search already
covers every Fin4 table, while the canonical positive-minimum classification
is now full debt versus reset rigidity.  Keeping the old local form as the
distinguished specialized search misstates its importance.

Either remove it, or rewrite it as a specialization to the current complete
terminal residual: a positive global-minimum joint law in the full-debt or
reset-rigid chamber, together with the exact source and unrestricted-cap
conditions needed by the proposed certificate.  A local strict-inert packet
alone must not be advertised as a normal form for a counterexample.

### 4. Eliminate the paid/reset umbrella duplication

`PAID_ADMISSIBLE_PAYOFF_NEAR_RETURN.md` is exactly the parent disjunction whose
two unresolved arms are asked separately in
`FIN4_PAID_RESET_REGENERATION_RANK.md` and
`FIN4_DOUBLE_UNIQUE_CAP_CLOSURE.md`.  It adds no third mathematical task.

The cleanest directory removes the umbrella and lets the two focused questions
stand.  If it is retained, the README must label it as an umbrella, not as an
additional open component, and its third bullet should be separated
grammatically from the two focused children.

### 5. Update the README hierarchy

The README should:

- retain full debt and reset rigidity as the only canonical terminal
  chambers;
- describe finite-clock descent, product-base descent, renewable-support
  exits, and the weak two-cut adapter as entrances to the shared off-minimum
  paid-cap waist, not as additional terminal components;
- replace the moving-cut link by the corrected weak two-cut consumer;
- replace the Jensen link by the response-curl/escaping-clock question;
- remove the obsolete strict-inert specialized search, if the file is removed;
- identify the paid/reset parent as an umbrella or remove it; and
- state that the exact-spine selection problem is an independent sufficient
  route, not an unfinished AGKRS theorem.

No AGKRS question should be added.  The conditional forward S.1/S.2/S.3 chain
is closed; the open exact-spine selection question is a different sufficient
producer problem.

## Missing-question check

After the rewrites above, I do not find another essential missing file.

- **Finite-clock descent:** no new question is needed.  The finite clock rank
  is already a valid producer and its terminal paid port is exactly the input
  of `FIN4_ACTUAL_PAID_CAP_DESCENT_OR_INERT_STALL.md`.
- **Weak two-cut producer:** no producer question is needed.  Rewrite the
  existing file to ask for consumption of its exact outputs.
- **Off-minimum paid port:** already covered centrally by
  `FIN4_ACTUAL_PAID_CAP_DESCENT_OR_INERT_STALL.md`, with specialized entrances
  in the product-base and renewal-exit questions.
- **Reset-rigid/full-debt:** both canonical chambers have dedicated questions.
- **Inert/cap switching:** the normalized inert question remains a valid
  conditional residual; the missing response-switch/clock formulation should
  replace the Jensen file.
- **AGKRS:** the conditional route is not an open question.  The exact-spine
  selection file remains useful because it asks for an independent sufficient
  producer, not for completion of AGKRS.

## Timelessness and self-containment

Except for the hierarchy corrections above, the files avoid Lean declaration
names, repository paths, commit history, and changelog narration.  The proposed
rewrites should preserve that rule.  Terms such as “checked”, “landed”,
“current”, or “existing theorem” should not be introduced.  State the supplied
mathematical object directly and ask for its consumer.
