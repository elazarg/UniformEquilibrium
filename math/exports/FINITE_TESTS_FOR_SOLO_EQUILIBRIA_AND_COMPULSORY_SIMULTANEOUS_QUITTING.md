# Finite tests for solo equilibria and compulsory simultaneous quitting

There are four private, independent stopping laws. The first nonempty quitting set A receives the original reward r(A), and perpetual play pays zero. Let sᵢ=rᵢ({i}), Zᵢ(A)=rᵢ(A)−sᵢ on nonempty coalitions, Γᵢⱼ=Zᵢ({j}) and Jᵢⱼ=Zᵢ({i,j}), using zero diagonals. A solo calendar has at most one possible quitter on every date. A complete deviation can change the entire stopping law. A collision is a first exit by two or more owners together.

Take G=Γ in the original centered units and assume it is invertible, with all off-diagonal entries nonzero. The following finite geometric tests suffice. Supply a nonsingular real diagonal matrix D with entries aᵢ such that DG is symmetric, and put A=DG⁻¹, also symmetric. Require

    { y≥0 : Σyᵢ=1, Gy≥0, yᵀDGy=0 } = ∅.                     (G)

For the interval branch with a negative own level, require that each owner i with a nonempty interval and sᵢ<0 have a distinct k with Gᵢₖ≤0. These are tests on reward entries. In fact it suffices for that branch to have one such eligible interval owner, or one with sᵢ≥0. The graph and exclusion when all intervals are empty require no row blocker.

The hypotheses cover every invertible positively diagonally symmetrizable R₀ matrix with nonzero off-diagonal entries. R₀ means no simplex y has Gy≥0 and yᵢ(Gy)ᵢ=0 for all i. Indeed choose a positive symmetrizer D; then yᵀDGy=0 on Gy≥0 would force that homogeneous complementarity system. Every column has a negative entry, or its singleton basis vector violates R₀, and the positive symmetrization gives a negative entry in each row. Below G,J and all payoffs use the same centered units, without any signed rescaling of preferences.

For example the more general signed certificate also works for D=diag(−1,−1,1,1) and G=D P, with

    P = [ 0, 2,−1, 2;  2, 0, 1,−5;  −1,1,0,3;  2,−5,3,0 ].

Its determinant is −39. The simplex section Gy≥0 has exactly the four vertices (0,0,2/3,1/3), (0,0,5/6,1/6), (0,1/5,2/3,2/15), (1/3,0,4/9,2/9). To verify the list, intersect the sum-one hyperplane with each triple from the eight linear inequalities y≥0, Gy≥0, retaining the feasible nonsingular intersections. All sixteen mutual P pairings of these four points are at least 22/45. Thus (G) holds although G has reciprocal entries of opposite signs. Every row has a negative entry. This example verifies only the parameter domain; J will determine the outcome of the calendar test.

If at least one original sᵢ is strictly positive, the following finite test decides whether there are arbitrarily accurate original equilibria whose probability of collision tends to zero. All other 32 native rewards are unrestricted. A positive outcome supplies an original uniform-equilibrium target. Add the original s to each centered target. In the graph branch the test computes the entire set of limiting vanishing-collision targets and every listed target has an exact eventually periodic solo equilibrium. A negative outcome gives a fixed positive lower bound on the unconditional probability of a simultaneous first exit **on one physical date** for every sufficiently accurate profile, whenever such profiles exist.

## The test

First form the four closed intervals

    Iᵢ = { h∈[0,1] : h Jⱼᵢ≤Gⱼᵢ for every j≠i }.

Under the interval-branch sign or weak-blocker condition, a nonempty eligible interval gives a positive outcome. Its elements are positive because every column has a negative entry: its own basis vector has zero quadratic energy, so a nonnegative column would violate (G). The named singleton is an attainable target. In this branch we make no claim to list all targets.

Suppose all four intervals are empty. Put M=max(1,max|Gᵢⱼ|,max|Jᵢⱼ|), δ=minᵢ minₕ∈[0,1] maxⱼ≠ᵢ(hJⱼᵢ−Gⱼᵢ)>0, and define

    K = {w=Gy : y≥0, Σyᵢ=1, E(w)=wᵀAw=0},
    γ = min_{w∈K} (−minᵢ wᵢ),          h₀=min(1/2, γ/(2M)).

K contains the four singleton columns. For w=Gy in K the inequality w≥0 contradicts (G). Thus γ>0 by compactness. Choose an integer L≥1 with (1−h₀)ᴸ<min(1/2,δ/(2M)). All tests up to this point are finite real polynomial feasibility or optimization; obtaining L requires only repeated multiplication by 1−h₀. There is no assertion of a common bound on L across input tables.

For each ordered pair of distinct owners a,b take the vertices (w,a,b) with w∈K, wₐ=wᵦ=0. There are at most 24 vertices. Indeed the complementary two-by-two principal block of A has determinant equal to the corresponding two entries of D multiplied together times −GₐᵦGᵦₐ/det G by Jacobi's minor identity. Its homogeneous binary quadratic equation E=0 therefore gives at most two real lines, and the affine equation Σᵢ(G⁻¹w)ᵢ=1 intersects each line at most once. Keep only the feasible simplex solutions. A vertex records a change from a to b.

From (u,a,b) to (v,b,c) allow any run of b of length 1≤k≤L. Its hazards h₁,…,hₖ and successive values u⁰=u,…,uᵏ=v must satisfy

    hₜ∈[h₀,1),     uᵗ⁻¹=hₜ G_{·b}+(1−hₜ)uᵗ,
    uᵗ⁻¹_b=uᵗ_b=0,       uᵗ⁻¹_j≥hₜ Jⱼᵦ  for all j≠b.

Each edge is a finite real feasibility test. Return a positive answer exactly when the graph contains a directed cycle. A productive vertex is one from which some cycle can be reached. To compute the full native target set when all Iᵢ are empty, take every productive vertex (v,b,c) and all initial b runs satisfying the same equations, with final value v and unrestricted initial value u. Their finitely many semialgebraic projections give exactly the target set; inclusion of runs of length zero is harmless because a productive vertex can itself begin the continuation along its first edge. If all sᵢ≤0 the original all-Continue profile is an equilibrium with zero collisions irrespective of the test; the full target classification above assumes some positive sᵢ.

There is a one-dimensional linear implementation of the run test, also for initial targets. With child v fixed, parametrize intermediate values by w(z)=G_{·b}+(v−G_{·b})/z, with z the reciprocal remaining run survival. A step from z to z′ uses hazard 1−z′/z. Starting from I₀=[1,1], construct Iₖ of possible z before k dates by projecting the following linear inequalities onto z:

    z′∈Iₖ₋₁,   1≤z′≤(1−h₀)z,
    (Gⱼᵦ−Jⱼᵦ)z+Jⱼᵦ z′≥Gⱼᵦ−vⱼ   for each j≠b.

Each projection is an interval, possibly empty or unbounded. One may cap z at 2M/δ throughout, since the first-date guard argument below applies to every remaining run. Check u=w(z) for z in the union of the first L intervals. After finding the vertices, this decision uses only intervals and linear inequalities in two variables.

## Why moving dates become a literal calendar

For any profile let ν be original joint Never, R the sum of its unrestricted centered regrets and C its first-exit collision probability. Write Sₜ for joint reach and wₜ for the conditional prescribed centered payoff. There is a constant K₀, depending only on the reward table and D, such that

    Sₜ² |E(wₜ)| ≤ K₀(R+C)                                      (1)

at every reached physical date. This also holds with a uniform perturbation error in the pair data, as shown below. For an exact solo date with sole owner i and hazard h, the identity behind (1) is E(wₜ)−(1−h)²E(wₜ₊₁)=2h aᵢ wₜ,ᵢ, since AG=D and Gᵢᵢ=0.

At a general date let q be its four hazards, c the row survival, xᵢ the probability of exactly singleton i and l the probability of at least two simultaneous quitters in that row. The unconditional-in-the-row exit contribution is e=Gx+b, where ‖b‖∞≤M′l for a finite bound M′≥1 on all native rewards. The payoff recursion w=e+cw⁺ yields E(w)−c²E(w⁺)=2eᵀAw−eᵀAe. Its principal term is 2Σaᵢxᵢwᵢ. Indeed xᵀDGx has absolute value at most a constant times Σᵢ<ⱼqᵢqⱼ≤6l by its zero diagonal. The remaining terms involving b are O(l) for a fixed table. The forced Quit offer Qᵢ is bounded by M′Σⱼ≠ᵢqⱼ in absolute value because quitting alone gives zero. Thus Σxᵢ|Qᵢ|≤12M′l.

Write Bᵢ,ₜ for each conditional full cap and dᵢ,ₜ=Bᵢ,ₜ−wₜ,ᵢ. Following the prescription until a reached date and then optimizing gives Sₜdᵢ,ₜ≤dᵢ,₁. Also Σₜ Sₜqᵢ(Bᵢ,ₜ−Qᵢ)≤dᵢ,₁: the one-stage loss of its assigned mixture against its optimal continuation is at least qᵢ(Bᵢ,ₜ−Qᵢ), and the remaining nonnegative losses telescope under joint survival. At every date |wᵢ|≤|Qᵢ|+(Bᵢ−Qᵢ)+dᵢ. Since xᵢ≤qᵢ and Σₜ Sₜ xᵢ≤1, summing Sₜ²Σᵢxᵢ|wᵢ| gives at most 2R+12M′C. Finally Sₜ wₜ→0, bounded by M′ times the probability of a finite prescribed exit on or after t. The energy identity telescopes to (1), even when ν>0. The unreachable child term at c=0 is zero.

Suppose R+C+ν→0, with all four intervals empty. Diagonally extract hazards and bounded conditional values at every fixed physical date, assigning arbitrary values after zero reach. At each date with positive limiting reach, its conditional Never and collision masses tend to zero, so its limiting w belongs to G times the simplex. It lies in K by (1) and the conditional debts tend to zero. At most one limiting hazard is positive because each conditional pair of quits has probability at most the conditional collision mass. Every limiting forced Quit offer is at least −Mh for the maximal hazard h, so h≥γ/M. No limiting row is sure: it would be a solo-i sure row with Jⱼᵢ≤Gⱼᵢ for all other j, contrary to Iᵢ empty. Inductively every fixed date has positive limiting reach and one proper active owner, and actual joint survival in the limit tends to zero geometrically. Thus the limiting prescribed values are the actual continuation payoffs of a literal absorbing calendar. If i acts, both supported actions are optimal in the limit because the caps at that date and its successor converge to their respective prescribed payoffs. In particular wᵢ=wᵢ⁺=0 and every quiet j has wⱼ≥hJⱼᵢ. These are exactly the tested comparisons.

For any finite initial portion of a same-i run, write S for its product survival and v for its actual next value. Its parent u=(1−S)G_{·i}+Sv has uⱼ≥h Jⱼᵢ at the first hazard h. Some j obeys hJⱼᵢ−Gⱼᵢ≥δ, so S≥δ/(2M) since |vⱼ−Gⱼᵢ|≤2M. With every hazard at least h₀ this bounds each such portion's length by L and excludes an infinite final run. At a change a→b, its value at the first b date has both coordinates zero by the preceding contact equations. Thus every switch gives a listed vertex and every complete intervening run a tested edge. The initial run ends at a productive vertex because there are infinitely many switches and only finitely many vertices. This proves necessity for every limiting initial target.

Conversely each productive path can be followed by periodic repetition of a cycle. The matching endpoint vectors and displayed edge inequalities make each stage Nash at the next value. The repeat includes two distinct owners and proper positive hazards, so every opponent family absorbs geometrically even when one player changes its whole law. Bounded annotated values consequently equal the actual prescribed and optimal values by iteration to infinity. This proves exact original equilibrium at the declared target for arbitrary signed row levels, since all unilateral replies absorb. Uniform geometric absorption after the finite initial part also gives the same fixed target for all sufficiently long average horizons at each accuracy.

For the interval branch, repeat h∈Iᵢ on solo i. The other owners' immediate offers hJⱼᵢ never exceed their perpetual waiting payoffs Gⱼᵢ, and every finite i action pays its singleton. If sᵢ≥0 its literal Never reply also cannot improve. In finite horizons i receives at most sᵢ from any reply, while the other players face geometrically decaying survival, which gives a uniform target. For sᵢ<0, run the solo i hazards for N dates and then let one rival k with Gᵢₖ≤0 quit with a small constant solo hazard η. Before the tail i can quit for its singleton. In the tail its native passive value is nonpositive and its native immediate offer is η Jᵢₖ, so every reply there is at most sᵢ+O(η); Never faces certain absorption. The prescribed i payoff differs from sᵢ by O((1−h)ᴺ). Every other owner's original prescribed payoff and every deadline comparison changes from an infinite i head by at most a reward bound times (1−h)ᴺ, since that owner faces the unchanged i head. Taking N→∞ and η→0 gives solo approximate equilibria at the singleton target, including when h=1. For each fixed N,η the named owner faces a geometric rival tail. Every other player either faces geometric opponent absorption too or reaches the tail only on the event of probability (1−h)ᴺ. Thus, after making that event as small as required, the terminal estimates give the same bounds over all sufficiently long average horizons, by the bounded early segment and the geometric absorption estimate on the other events.

## Which profiles the test decides

An original player with sᵢ>0 has signed regret at least sᵢν by moving its Never mass to arbitrarily late finite dates. Each centered regret is at most its signed regret plus |sᵢ|ν, since centered finite deadlines approximate literal Never and every original finite deadline receives the added sᵢ. Thus any original near-equilibrium sequence with vanishing collisions has R+C+ν→0. Compactness permits extracting a target whenever only existence of a sequence was specified.

Rejection persists on one neighborhood of the 24 pair entries and allows the 32 other entries to be chosen arbitrarily and separately. Here is the uniformity argument when even their bounds may vary from table to table. If this failed, there would be perturbations Gₙ,Jₙ→G,J of pair error εₙ, completions bounded respectively by Mₙ≥1 and profiles with Rₙ+νₙ+(1+Mₙ)³Cₙ→0. Choose one sufficiently accurate profile per viable completed table. In (1) retain the fixed reference A,G. The decomposition error b now has ‖b‖∞≤εₙ |x|₁+Mₙl, and Sₜ‖wₜ‖∞≤M₀Sₜ+Mₙ Cₙ by splitting all future first exits into singleton and multiple exits, where M₀ bounds every singleton matrix in the sequence. The contribution of 2bᵀAw to the sum with weights Sₜ² is thus O((εₙ+MₙCₙ)(M₀+MₙCₙ)) since Σₜ Sₜ|x|₁≤1 and Σₜ Sₜl=Cₙ. The error from replacing e by Gx in eᵀAe has summed absolute value O(εₙ+εₙ²+(1+Mₙ)²Cₙ), by |x|₁,l≤1. The forced-Quit and cap loss bounds above give O(Rₙ+Mₙ Cₙ) for the assigned terms. Therefore supₜ Sₜ²|E(wₜ)|→0. At any fixed positive limiting reach the limiting payoff again lies in G times the simplex. Absolute errors from multiple first exits are ≤Mₙ Cₙ/Sₜ. The immediate forced offer conditional on one hostile rival can change by O(εₙ), and all rewards involving two or more rivals at that date contribute at most O(Mₙ Cₙ/Sₜ); thus the limiting sole-date guards use the original J. The identical physical extraction produces a graph cycle at the rejecting reference table. This contradiction gives one pair neighborhood, with signed own levels allowed to vary subject to at least one positive. The numerical collision floor need not be uniform in unbounded higher completions.

If the maximum unconditional simultaneous-exit probability on any date is ≤u, then at a date of reach ≥a the second largest hazard is at most √(u/a) by testing the top two. The probability of any simultaneous exit there, conditional on reaching it, is at most six times the largest hazard times √(u/a). The sum of reached largest hazards is ≤1. Dates of reach <a contribute at most a to the total first-exit probability. Hence C≤6√(u/a)+a, tending to zero with u by taking a=u^(1/3). This upgrades the rejection to a positive one-date collision floor.

## A four-pulse decision without symmetry or invertibility

Fix a perfect matching m. Assume all eight crossed singleton differences are strictly negative, and all four matched joining rewards are strictly positive. Both matched singleton directions on either pair may have arbitrary signs. The remaining 32 higher rewards are free. With at least one positive original own level, the following three tests decide the existence of arbitrarily accurate original equilibria with vanishing collisions.

* A nonempty interval Iⱼ gives the singleton target by the earlier construction, since each row has a hostile crossed opponent.
* A simplex point y with Gy=0 gives the original own-singleton vector as a limiting target, as shown below.
* If neither preceding test passes, it is necessary and sufficient for one of the two orientations around the crossed four-cycle to admit an exact four-pulse calendar. This is finite polynomial feasibility: take one hazard 0<hⱼ<1 and value uʲ for each phase, and impose the singleton recursion, zero current and next values for the active owner, and the three quiet inequalities uʲᵢ≥hⱼJᵢⱼ. Every feasible calendar works at every signed own level. If neither orientation passes, every sufficiently accurate original profile has a positive probability of a collision on one physical date.

The complete matching target set is also computable. Without a simplex kernel, the cyclic part comprises at most eight polygons of at most six vertices each. Every point of the cyclic part has an exact private equilibrium. With a simplex kernel the cyclic part consists of the origin and at most four triangles of limiting targets. The nonempty singleton intervals add the columns or segments specified below.

For the next argument it suffices that each row i has Gᵢⱼ<0 for its two crossed owners j∉{i,m(i)}, with Gᵢᵢ=0 as usual. Start with a sequence of independent profiles with centered total regret R, total first-exit collision probability C, and joint Never probability ν tending to zero. Write wₜ for the centered prescribed payoff conditional on reaching date t, Sₜ for that reach, qᵢ for its hazards, xᵢ for its conditional probability of precisely singleton i, and l for its conditional probability of a multiple exit. Let M≥1 bound all centered rewards. The full-cap Bellman inequality above gives

    Σₜ Sₜ² Σᵢ xᵢ |wₜ,ᵢ| ≤ 2R+12MC.

Indeed at a reached date |wᵢ|≤|Qᵢ|+(Bᵢ−Qᵢ)+dᵢ for the forced Quit offer Qᵢ, full cap Bᵢ and regret dᵢ. Since quitting alone pays zero, |Qᵢ|≤MΣⱼ≠ᵢqⱼ and Σxᵢ|Qᵢ|≤12M l. The root regret dᵢ,₁ bounds both Sₜdᵢ,ₜ and Σₜ Sₜ qᵢ(Bᵢ−Qᵢ), by conditional replacement and the telescoping nonnegative losses on assigned actions. Also Σₜ Sₜ xᵢ≤1.

On a copy of [0,1] put consecutive intervals in physical order, of lengths SₜΣᵢxᵢ. On each positive-length interval put λᵢ=xᵢ/Σⱼxⱼ. Their total length is 1−C−ν. Use any fixed probability vector on the remaining interval. Put W(z)=∫_z¹ Gλ(v)dv. At the beginning of date t's interval W differs from Sₜwₜ by at most M(2C+ν), by discarding the remaining multiple exit rewards and inserting the final interval. Within the interval its ith coordinate changes by at most M SₜΣⱼ≠ᵢxⱼ, since Gᵢᵢ=0. Weighted by λᵢ and integrated on that interval, this variation costs at most M Sₜ² xᵢ Σⱼ≠ᵢxⱼ. Summation over owners and dates gives at most 12M C. The artificial interval contributes O(M(C+ν)). Thus ∫₀¹ λᵢ|Wᵢ|→0 for every owner. Extract uniformly converging primitives of λ by compactness of bounded Lipschitz functions. Their derivatives give a measurable probability vector λ(z) almost everywhere; the original λᵢ converge as measures against continuous tests by convergence of the primitives. The payoffs W converge uniformly to W(z)=∫_z¹Gλ. Consequently λᵢ(z)Wᵢ(z)=0 almost everywhere for every i, and W(0) is the subsequential limiting original centered payoff.

No matched pair can have both W coordinates strictly positive at any z<1. On such an open region both their activities vanish almost everywhere, so both coordinates are nondecreasing there: only crossed owners can move them and their singleton rewards are negative. Hence the two strictly positive coordinates cannot exit the region forward and cannot end at W(1)=0. Now if W(z)≥0 and Wₐ(z)>0 for some a and z<1, its mate i must have Wᵢ(z)=0. On a short right interval Wₐ stays strictly positive, so λₐ=0 almost everywhere and Wᵢ is nondecreasing. It cannot become positive while Wₐ is positive, hence it stays zero. Its derivative therefore forces both crossed activities to vanish almost everywhere on the interval. Only i acts there. The two crossed coordinates, nonnegative at the start, immediately become strictly positive together, contradicting the first conclusion. This proves that a nonnegative W(z) with z<1 is necessarily zero.

If no simplex y satisfies Gy=0, the initial payoff in every such limiting profile has a strictly negative coordinate. The separation is uniform for the fixed G: the class of absolutely continuous paths just obtained is compact in the primitive topology by the same argument, and W(0)=Gy for a simplex y. The argument also applies to the conditional laws at every cut with positive limiting reach, by the conditional regret bound and the conditional first-exit probabilities. Thus a common negative margin is available on all those cuts, without a quadratic form, any matrix inverse, or restrictions on the matched singleton entries.

If some simplex y instead satisfies Gy=0, at least two yᵢ are positive, since every singleton column has a strictly negative crossed entry. Use independent stationary hazards εyᵢ. Prescribed play and every unilateral deviation face almost sure rival absorption. The prescribed native payoff is O(ε), since singleton probabilities per date are εy+O(ε²), joint exits have probability O(ε²) per date and total per-date absorption is ε+O(ε²). For each owner its immediate native Quit offer is O(ε); its perpetual passive payoff is O(ε) since the rival absorption rate is ε(1−yᵢ)+O(ε²) and Σⱼ≠ᵢ Gᵢⱼ yⱼ=0. A finite deadline's payoff interpolates between these offers by geometric summation. The family gives vanishing complete regret and O(ε) total first-exit collision probability. Adding arbitrary signed own levels shifts every prescribed and unilateral payoff by the full row constant; the limiting original uniform target is s by the geometric rival absorption for each fixed ε. The singular-boundary calculation below gives the other possible targets in this case.

The strictly positive own level converts vanishing original regret and collisions into R+C+ν→0 as above. On the branch with no simplex kernel and empty intervals, the negative-coordinate bound gives the same physical extraction as in the graph proof: each limiting row has exactly one proper nonzero hazard bounded uniformly below. A sure solo row would give 1∈Iⱼ. Every finite date retains positive limiting reach, the resulting calendar absorbs geometrically, the active owner has zero current and next values, and the three quiet comparisons hold. No owner can act forever without another switch since its current hazard would then belong to its own interval.

Fix one of the two orientations, with consecutive owners p,j,k,l around the crossed four-cycle, so l is matched to j. At a switch p→j the two labeled coordinates vanish. Its positive joining comparison makes the mate l strictly positive, and the negative-coordinate bound makes k strictly negative. A matched switch is impossible by the preceding owner's zero value and positive joining offer. An immediate reversal is impossible because the previous owner's value would be zero at both ends of a nonempty intervening run with strictly negative crossed singleton reward. Hence switches follow a single orientation forever.

For one full j run let u,v be its beginning and ending conditional values, let g=G_{·j}, and let H be its total conditional exit probability. Thus u=Hg+(1−H)v. The first guard gives Jₚⱼ≤0. Also vₖ=0, so uₖ=HGₖⱼ<0, and its first hazard at most H gives Jₖⱼ≤Gₖⱼ. For the mate, let h be the last hazard. Since vₗ<0 its last guard gives Jₗⱼ≤Gₗⱼ+(h⁻¹−1)vₗ≤Gₗⱼ+(H⁻¹−1)vₗ=uₗ/H. All comparisons therefore hold for one pulse with hazard H. In particular any viable tour has all four matched singleton entries positive, since uₗ>0 and vₗ<0.

## Computing every target on the crossed four-cycle

At a switch into j use the *unconditional* remaining singleton payoff W, the conditional value multiplied by reach. It lies in the plane Wₚ=Wⱼ=0. The absolute first-exit mass b at this phase and the next unnormalized state W′ are forced by the next owner's zero value:

    b = Wₖ/Gₖⱼ,                 W′ = W−b G_{·j}.                 (2)

The map is invertible between successive coordinate planes, since b=−W′ₚ/Gₚⱼ recovers the discarded mass. The sign and incentive conditions are the linear inequalities Wₗ≥0, Wₖ≤0, Wᵢ≥bJᵢⱼ for all i≠j. At a fixed starting phase compose the four linear maps (2) to obtain a two-dimensional invertible return map T. Let K be the closed convex cone of starting states satisfying these inequalities at all four successive phases. It is pointed, being contained in the initial sign quadrant. Let B(W) be the sum of the four masses from (2), a linear functional, and let S be the real stable subspace of T, the sum of its real generalized eigenspaces for eigenvalues of modulus less than one, including the real planes of any nonreal conjugate pair with that modulus. Define

    V = { W∈S : TⁿW∈K for every integer n≥0 }.

There is a finite real-algebraic test for membership in V. Seek at most two vectors in S∩K whose nonnegative span contains W and contains the images of both vectors under T. This suffices by induction. Conversely V itself is a closed pointed convex cone in a plane, so has at most two generating rays, including its zero and ray degeneracies. Its generators satisfy the test. Thus one can compute V by projection of finitely many real polynomial equalities and inequalities. The stable subspace is obtained by ordinary real matrix algebra in dimension two.

For any nonzero W∈V each future mass is strictly positive. If b=0 at a phase, its k coordinate vanishes and W′=W. At the next phase the matched and remaining coordinates are p and l, respectively, so Wₗ is both nonnegative and nonpositive. Then W=0, contrary to invertibility. The absolute mass of the infinite tail is the positive linear functional on this cone

    L(W) = B((I−T|S)⁻¹W).

Indeed this is the convergent sum of B(TⁿW), since W belongs to S. Conversely every absorbing infinite calendar gives a state in S because its unconditional remaining payoffs tend to zero. For W∈V, telescoping (2) shows that its actual remaining payoff is W as its future states tend to zero. Normalize by L(W) to obtain probability one, and on each date use the hazard b divided by the remaining mass. The slice V∩{L=1} is compact since L>0 on its unit directions. On each nonempty phase slice the first mass is continuous and strictly positive, while a further positive mass remains. Thus all these calendars have every hazard bounded away from zero and one, uniformly in the four phases for this table and orientation. Every unilateral change faces geometrically absorbing rivals, and the tested complete-reply bounds follow by iterating the one-stage inequalities. This realizes every such tail on private independent clocks, at arbitrary signed own levels.

For existence it even suffices to test four pulses repeated periodically. On a nonempty normalized slice the map W↦TW/L(TW) is continuous into the same compact interval or point. It has a fixed point. Its invariant ray gives four repeating conditional hazards, all strictly between zero and one. This proves necessity of the finite four-pulse test, in addition to its sufficiency.

The entire target set follows from allowing an initial j pulse before a tail starting at the switch j→k. Take the corresponding tail cone V and introduce its subnormalized state W and an initial mass d. Impose

    W∈V,     d≥0,     d+L(W)=1,
    z=d G_{·j}+W,       zᵢ≥d Jᵢⱼ for i≠j.                      (3)

This allows every actual first j run. To see that it compresses, the child's l coordinate is negative, so the last guard gives the mate comparison at the compressed hazard as before. Its k coordinate is zero, giving Jₖⱼ≤Gₖⱼ. The full tour gives Jₚⱼ≤0, so the p guard follows from the first date when zₚ<0 and holds directly when zₚ≥0. Conversely, (3) gives the one initial pulse followed by the constructed tail. Here d=1 would give 1∈Iⱼ, and d=0 would require its nonzero child W to be nonnegative. The latter is impossible since its next-owner coordinate is strictly negative by (2) and the positive mass there. The current owner's prescribed and next values are zero. Thus the guarded initial pulse and tail give exact original equilibrium at s+z. No limit of the construction is needed to realize its targets.

The normalized cone in (3) before imposing the three guards is a triangle or one of its degeneracies: its rays come from the d axis and the at most two generators of V, all with strictly positive normalizing value. Three half-planes cut out a polygon with at most six vertices. Linear projection to z preserves this upper bound. The two orientations and four initial owners therefore give at most eight closed polygons in payoff space, each of dimension at most two. Their union shifted by s equals the entire set of limiting vanishing-collision targets on the empty-interval, no-simplex-kernel branch. Every point has an actual solo equilibrium, whose tail may vary from cycle to cycle. Rejection on both orientations gives the physical one-date collision floor by the earlier estimate.

### A polygon with targets requiring nonperiodic solo play

The two-dimensional case occurs, and some exact targets require a nonperiodic solo calendar. In the forward cyclic order write p,j,k,l for consecutive labels and set the entries in every column j to (Gₚⱼ,Gₖⱼ,Gₗⱼ)=(−1,−6,5) and (Jₚⱼ,Jₖⱼ,Jₗⱼ)=(−1/2,−7,1). All 32 higher entries are free. Each interval is empty by the predecessor inequality, the reverse orientation fails its successor comparison, and the common column sum −2 precludes a simplex kernel. On the forward tour the absolute exit masses rₙ satisfy 6rₙ₊₁=5rₙ−rₙ₋₁: the mate coordinate at switch n is rₙ₋₁ by the preceding zero, while the value recursion gives 5rₙ−6rₙ₊₁ for the same coordinate. Both positive roots λ=1/2 and λ=1/3 give normalized masses rₙ=(1−λ)λⁿ, n≥0. The matched guard compares rₙ/λ with rₙ and the two crossed guards hold strictly. The normalized switch payoffs entering k, in coordinates (p,j,k,l), are respectively (1,0,0,−3) and (2,0,0,−4). Their convex mixtures are realized by mixing the absolute date masses and implementing their conditional hazards.

Write the mixed child as (a,0,0,−2−a) with 1<a<2. Prepend one j pulse of hazard h. At h=3/5 all three first-pulse comparisons are strict even at a=1,2. They continue to hold on a common open interval about 3/5. The coordinates zₖ=−6h and zₚ=−h+(1−h)a of the resulting native target recover h and a separately. This gives a relatively open two-dimensional set of exact original targets s+z. On a smaller open rectangle, for example with a near 5/4, j is the unique zero coordinate of z.

For at least one positive original own level, any exact solo equilibrium at one of the latter targets starts with j, since every active owner has zero centered value. Its switches follow the forward orientation. Even if every same-owner run is split across several physical dates, its first total hazard equals the recovered h because the ending k coordinate is zero. Thus its normalized first switch equals the specified child, and (2) forces the complete successive run masses. Those masses have two nonzero coefficients multiplying (1/2)ⁿ and (1/3)ⁿ. An eventually periodic physical calendar would repeat its list of runs and within-run hazards after some fixed number P of switches, making rₙ₊ₚ/rₙ constant for all sufficiently large n. A sum of two positive geometric sequences with distinct ratios cannot have this property. The area of attainable targets therefore persists even after every eventually periodic solo equilibrium target is removed from this open rectangle.

## All limiting targets on the singular matching boundary

Write $g_{ij}=G_{ij}$. Suppose all crossed $g_{ij}$ are strictly negative, all four $J_{m(j),j}>0$, all four intervals $I_j=\{0\le h\le1:hJ_{ij}\le g_{ij}\ (i\ne j)\}$ are empty, and $Gy=0$ for some vector $y$ in the simplex. All higher rewards are arbitrary finite reals. Assume at least one $s_i>0$ for necessity. A limiting target here means the limit of original expected payoffs at vanishing complete regret and vanishing probability of a simultaneous first exit. Every target produced below is also a uniform-equilibrium payoff at arbitrary signed levels.

The centered target set is the origin together with at most four closed triangles. Original targets are obtained by adding $s$. To compute the triangles, take a positive left null vector $L^TG=0$. For either orientation of the four-cycle of crossed edges write $p,j,k,l$ for predecessor, incumbent, successor and $l=m(j)$. Define
$$
 b_j=1/(-g_{pj}),\qquad a_j={(-g_{kj})L_k\over(-g_{pj})L_l},
 \qquad T_j(t)={a_jt\over1+b_jt}.
$$
Keep an orientation exactly if $A=\prod_j a_j>1$ and each phase satisfies
$$
 J_{pj}\le0,\qquad J_{kj}\le g_{kj},\qquad
 J_{lj}\le g_{lj}+g_{pj}L_p/L_l.
$$
The two products $A$ are reciprocals, since the $L$ factors cancel. At most one orientation can pass. Its unique positive periodic solution $t_j^*=T_j(t_k^*)$ is explicit: a whole backwards turn has the form $At/(1+Bt)$ with $B>0$, so its positive fixed point is $(A-1)/B$. At the start of phase $j$ put $U^j_p=U^j_j=0$, $U^j_l=t_j^*$, $U^j_k=-L_l t_j^*/L_k$. For each $j$ take the triangle with vertex zero and opposite interval
$$
 w(H)=H G_{\cdot j}+(1-H)U^k,\qquad
 0\le H\le1,\quad w_i(H)\ge HJ_{ij}\ (i\ne j).
$$
The interval is closed, possibly a point, and contains the cycle's own pulse. Neither endpoint $H=0,1$ passes. With no passing orientation the target set consists of the origin alone.

**Physical extraction.** Every coordinate of $y$ is positive. If $y_{m(i)}=0$, row $i$ forces both crossed weights zero and only singleton $i$ remains, contradicting a strictly negative crossed entry in that column. To see that $L>0$ exists, let $P$ swap mate columns and $K=GP\operatorname{diag}(Py)$. Its row sums vanish and its off-diagonals are negative on the connected crossed square, zero elsewhere. For small $\tau>0$, $I-\tau K$ is an irreducible stochastic matrix. A positive stationary vector gives $L^TK=0$, hence $L^TG=0$.

For a sequence witnessing a limiting target, write $\nu$ for joint Never. Moving its owner's Never mass to arbitrarily late finite deadlines gives original regret at least $s_i\nu$ when $s_i>0$. Every finite deadline adds the full $s_i$ to its centered return, and centered finite deadlines approximate literal Never. Thus $\nu\to0$ and each centered regret tends to zero. At every fixed date take a common diagonal subsequence of prescribed conditional values and all hazards. On positive limiting reach the conditional centered debts, Never mass and collision probability vanish, by conditioning (conditional debt times reach is bounded by initial debt). Consequently its limiting value $u$ is in $G\Delta$, so $L^Tu=0$. At most one limiting hazard is positive, by independence and vanishing conditional collisions. If $u\ne0$ it has a negative entry and some hazard must be positive, since with all hazards tending to zero every immediate Quit offer tends to zero. It cannot be sure, since then the quiet comparisons give $1\in I_j$. Write $q$ for the sole positive limiting hazard of $j$, and $v$ for the next value. The limiting comparisons give
$$
 u=qG_{\cdot j}+(1-q)v,\quad u_j=v_j=0,\quad u_i\ge qJ_{ij}\ (i\ne j).
$$
Indeed the prescribed mixture has vanishing debt against both supported actions, including Wait followed by optimal continuation since the child has positive limiting reach. If $v=0$, the quiet guards again give $1\in I_j$. Starting at any nonzero target this proves by induction that every physical date has positive reach and a proper pulse with nonzero value. It requires no uniform lower bound on the hazards.

A permanent final run of one owner $j$ is impossible. If its hazards have divergent sum the limiting recursion forces its value everywhere to be $G_{\cdot j}$, contrary to the first quiet guard and $I_j=\varnothing$. If they are summable they tend to zero. All values there have every coordinate at least $-M q$ by the quiet guards and the zero active value, for a fixed reward bound $M$. Since $L^Tu=0$, the values tend to zero. The run's initial value is therefore $HG_{\cdot j}$ with $H=1-\prod(1-q)>0$. The first hazard divided by $H$ belongs to $I_j$, another contradiction. This rules out an arbitrary escaping residual payoff in a final run.

**Switches and scales.** A matched switch $p\to j$ is impossible since $u_p=0$ and its offer would be positive. An immediate reversal $p\to j\to p$ puts both endpoints at zero in coordinate $p$ despite $g_{pj}<0$ and positive absorption in the intervening run. Thus infinitely many switches follow one orientation. At each switch $u_p=u_j=0$, the mate $l$ has positive value by its offer, and the other coordinate is strictly negative by $L^Tu=0$. A full $j$ run from $u$ to its next switch $v$ has total hazard $H=v_p/(v_p-g_{pj})$, which follows from the recursion in row $p$. Its mate coordinate at the start is $u_l=T_j(v_p)$, using $v_l=-L_p v_p/L_l$ and column $j$ of $L^TG=0$.

The first hazard $q\le H$ gives $J_{pj}\le0$ and $qJ_{kj}\le Hg_{kj}<0$, hence $J_{kj}\le g_{kj}$. At the last hazard $q'\le H$ the mate guard gives $J_{lj}\le g_{lj}+(1/q'-1)v_l\le g_{lj}+(1/H-1)v_l=g_{lj}+g_{pj}L_p/L_l$. These are also sufficient for a single pulse with these endpoints. Along a full positive orbit, reciprocals of the values at a fixed phase obey $z_{n+1}=A z_n-B$ in forward time. With $A\le1$ they eventually fail positivity, and if $A>1$ their initial value is at least $B/(A-1)$. Thus every actual switch $v$ is $cU^k$ for some $0<c\le1$ at its phase. The positive periodic solution realizes the stated vector recursions and all guards. Its proper four-pulse calendar absorbs geometrically even after any owner deviates.

The initial $j$ run also compresses to one pulse of its total hazard $H$. The first predecessor guard implies the compressed guard since $J_{pj}\le0$, the successor's value is $Hg_{kj}$, and the mate uses the last guard with $v_l<0$ as above. Writing $v=cU^k$ and $d=H+(1-H)c$, its initial value is $d w(H/d)$. The compressed quiet inequalities give exactly those tested on $w(H/d)$. This proves necessity of the triangles even if a positive limiting survival persists at physical infinity.

**Realization.** A stationary tail with independent hazards $\epsilon y_i$ gives each owner prescribed centered value and full centered cap of magnitude $O(\epsilon)$. Singleton contributions cancel to first order by $Gy=0$; the rate of multiple exits is $O(\epsilon^2)$ per date against total absorption rate $\epsilon+O(\epsilon^2)$. For owner $i$ the passive rate against the other owners is $\epsilon(1-y_i)+O(\epsilon^2)$, with zero first-order payoff numerator, and the forced Quit offer is $O(\epsilon)$. Every finite deadline is an interpolation of these two values. Every rival family absorbs geometrically, including against literal Never. This proves the origin case.

Start now with any admissible single initial pulse and its periodic tail realizing $w(H)$, with reaches $S_n$, values $V_n$, and solo hazards $q_n$. For $0<d<1$ prescribe before a cutoff the solo hazards
$$
 S'_n=1-d+dS_n,\qquad q'_n=dS_n q_n/S'_n,\qquad V'_n=dS_n V_n/S'_n.
$$
The new reach has the displayed value by induction. Every exact annotated Bellman equality and quiet inequality holds with terminal annotations $V'_n$, by multiplication by $dS_n/S'_n$. The annotations tend to zero. At date $N$ replace the remaining play by the stationary tail above. Both prescribed and optimal centered payoffs on that tail differ from $V'_N$ by at most $O(\epsilon)+\|V'_N\|_\infty$. The prescribed and best-response Bellman updates are nonexpansive in the continuation values, so the same error bound holds throughout the finite prefix even when a deviator would have positive survival forever on its untruncated law. The true stationary tail absorbs against every deviation, shifts every return by the full original row constant and has conditional collision probability $O(\epsilon)$ after a collision-free prefix. For each accuracy choose $\epsilon$ small and $N$ large. Finite horizons converge uniformly over deviations because after the fixed cutoff all rival survival tails decay geometrically. The original limiting uniform payoff is $s+d w(H)$. For $d=1$ the exact absorbing calendar suffices. This proves sufficiency including the triangle boundaries.

For example take cyclic $g_{pj}=-1$, $g_{kj}=-2$, $g_{lj}=3$, and $J_{pj}=-1/2$, $J_{kj}=-3$, $J_{lj}=1$ everywhere on that orientation. Both null vectors are constant, each interval $I_j$ is empty, $T_j(t)=2t/(1+t)$ and $t_j^*=1$. Each opposite interval has $1/3\le H\le2/3$ with coordinates $(1-2H,0,-2H,4H-1)$ in order $(p,j,k,l)$. The four triangles each have nonempty relative interior. The entire calculation uses the singleton and joining coordinates only.

## What a nonempty singleton interval adds to the matching target set

Keep the eight strict crossed singleton comparisons and four positive matched joining rewards. For necessity take at least one positive own singleton level. At d=1 in (3) with a nonzero cyclic cone, place any normalized exact tail from that cone after the sure j pulse. ## A sharp threshold in twelve independent singleton coordinates

There is an open neighborhood of the matrix G⁰ with matched 3 and crossed −1 in all twelve independent singleton entries where the exact cycle and whole target set admit explicit formulas. Indeed G⁰ is invertible, so the simplex-kernel branch is absent throughout a neighborhood. Shrink it so that a=1ᵀG⁻¹ is defined and close to 1ᵀ. For successive switches of an absorbing calendar, write p,j,k,l for the previous, current, next and matched-to-current owners. For the realized child v, a v=1, vⱼ=vₖ=0 and vₚ=t>0, so vₗ=(1−aₚt)/aₗ<0. Thus 1/2<t<5 by the signs and bounded singleton columns. Define

    Sⱼ(t)=−Gₚⱼ/(t−Gₚⱼ),
    Tⱼ(t)=Gₗⱼ+Sⱼ(t)((1−aₚt)/aₗ−Gₗⱼ).

The positive mate coordinate at the preceding switch is Tⱼ(t). At G⁰ each of these backward maps is (1+2t)/(1+t), sending [1/2,5] strictly inside itself with derivative at most 4/9. On a sufficiently small common neighborhood all eight maps (four phases in either orientation) are self-maps of that interval with a common Lipschitz constant b<1. Each orientation therefore has a unique cyclic solution tⱼ=Tⱼ(tₖ), analytic in G by the implicit function theorem. Every infinite admissible switch sequence coincides with it: comparison with its N-th successor bounds the difference from the corresponding periodic value at any fixed switch by bᴺ times the interval diameter. Put Hⱼ=1−Sⱼ(tₖ) and Uʲₚ=Uʲⱼ=0, Uʲₗ=tⱼ, Uʲₖ=(1−aₗtⱼ)/aₖ. The full vector recursion follows by matching the two specified zero coordinates and the mate coordinate, then using aG_{·j}=1. These payoffs retain the strict sign pattern of the central cycle by continuity.

With all matched J positive and all Iⱼ empty, an orientation passes exactly when, at each j,

    Jₚⱼ≤0,    Jₖⱼ≤Gₖⱼ,    Jₗⱼ≤tⱼ/Hⱼ.

For each passing orientation and phase j the possible initial targets of a run ending at its canonical switch into k comprise the closed segment

    w(h)=h G_{·j}+(1−h)Uᵏ,   0≤h≤1,   wᵢ(h)≥hJᵢⱼ for i≠j.

It contains h=Hⱼ; h=0 is excluded by a negative coordinate of Uᵏ, and h=1 by the empty interval. For a possibly truncated initial run, the first-date guard implies wₚ(h)≥hJₚⱼ because Jₚⱼ≤0. The k guard follows from Uᵏₖ=0 and Jₖⱼ≤Gₖⱼ. The mate guard follows by the same last-date argument since Uᵏₗ<0. Conversely the compressed single initial pulse satisfies all comparisons and is followed by the genuine periodic tail. Hence after adding the own singleton vector these at most eight segments are the entire limiting vanishing-collision target set, and every listed target has an exact eventually periodic original equilibrium.

In particular fix 0<d<1, 0<3c<(3+√5)/2, set Jⱼ₋₁,ⱼ=−(1−d) and Jⱼ₊₁,ⱼ=−(1+d) at the reference, and set the three matched J other than x=J₂₀ to 3c. Throughout an open neighborhood in the other 23 pair-data entries, all four intervals remain empty and only the forward orientation can pass. Its crossed and three nondesignated matched guards are strict. Consequently 0<x≤t₀(G)/H₀(G) is necessary and sufficient for vanishing collisions; this real-analytic boundary equals (3+√5)/2 at G⁰. Above it every sufficiently accurate profile has a positive probability of a collision on one date. All 32 higher rewards are free on both sides.

At this center write $\rho=(3-\sqrt5)/2$, $h=1-\rho$ and $B=(1+\sqrt5)/2$. Indeed $B=(1+2B)/(1+B)$, $S_j(B)=\rho$, and $B/h=(3+\sqrt5)/2$. On the successful side, in coordinates $(p,j,k,l)$ the four target segments are given by

$$((1-H)B-H,\ 0,\ -H,\ 3H-(1-H)h),\qquad \frac{h}{3+h-J_{lj}}\le H\le\frac{B}{B+d}.$$
