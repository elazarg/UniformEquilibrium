# Fin4 neutral chronology problem

This file states the Fin4 producer problem left after the abstract occupation
consumer. It is a target, not an established reduction.

## Required input to the abstract consumer

Starting from a positive-minimum Fin4 source, construct a compact or otherwise
recurrence-complete system of actual source packets and literal chronological
edges such that:

1. every edge executes a finite block and reaches its displayed successor;
2. source and successor carry the same exact semantic, law, and punishment
   data used by the edge certificate;
3. the system is closed and serial, or has a separately proved replacement
   for invariant-occupation existence;
4. every positive charge decodes to an admissible payoff edge with a fixed
   threshold; and
5. every stated rank decrease is renewable after source reconstruction.

The current source-preserving reductions do not yet supply all five fields in
one system. In particular, source replacement, minimizer reselection,
normalization, and compact limits are horizontal operations until a literal
commuting seam is proved.

## Neutral invariant core

Suppose such a system has been constructed, with nonnegative admissible charge
\(q\), a finite rank \(\rho\), and terminal set \(T\). Positive-mean invariant
occupations are consumed by chronological near-return. Invariant occupations
assign zero mass to strict rank descent. The remaining candidate obstruction
is therefore an invariant occupation supported on

\[
\mathcal N_r=
\left\{
e:
q(e)=0,
\ \rho(t(e))=\rho(s(e)),
\ s(e),t(e)\notin T
\right\}.
\tag{1}
\]

The missing theorem is to show that every actual source-matched invariant
occupation on this neutral set has one of the following consequences:

1. contradiction with the positive-minimum hard residual;
2. an exact nonrealizability certificate;
3. a forced renewable exit from the neutral set; or
4. a concrete reward table with an independently certified positive
   exploitability gap.

This statement is useful only after the chronological system itself has been
produced. Without that producer, “neutral core” merely renames the original
chronology problem.

## Concrete forms of the missing producer

For the source objects currently isolated in Fin4, two concrete routes would
supply the needed chronology:

- nested compatibility of the retained suffix atom, yielding one actual
  chronology with nonvanishing admissible charge; or
- exactification of repeated support transitions into successor-compatible
  Nash--Bellman and punishment edges with renewable source reconstruction.

A scalar debt decrease is insufficient if the decrement can vanish or source
regeneration resets the comparison. A repeated support label is insufficient
if support entry and support drop alternate. A balanced normalized occupation
is insufficient if it has no absolute behavioral profile, payoff, cap, law,
or executable seam.
