# Historical audits

This directory preserves dated or superseded synthesis that remains useful for
provenance, falsifier history, and source reconstruction. Its files are not
current status authorities and may retain source-repository paths or commit
locators.

Use these live documents instead:

- [`../SEMANTICS.md`](../SEMANTICS.md) for the stable model contract;
- [`../STATUS.md`](../STATUS.md) for generated headline declarations;
- [`../FRONTIER.md`](../FRONTIER.md) for the current mathematical boundary;
- [`../TOOLKIT.md`](../TOOLKIT.md) for integrated interfaces; and
- [`../PIPELINE.md`](../PIPELINE.md) for the Discussion → Issue → PR workflow.

Historical files should begin with a notice naming the live replacement. Do
not update them merely to mirror current theorem status.
